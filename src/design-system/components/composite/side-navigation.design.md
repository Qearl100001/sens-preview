# 侧边导航 Side Navigation · 设计规范

> 来源：Figma `设计系统 2.1 侧导航设计`，节点 `1777:110915` / `1777:111170`；单层带图标场景来自 `18593:101880` / `18593:101946` / `18593:101979`；二级带图标 / 三级无图标场景来自 `18596:105388` / `18596:105418` / `18596:105425`；分析专属场景来自 `18527:121293` / `18540:99716` / `18527:121314`。
> 定位：产品壳专属导航组件。它不等同于页面内的锚点、目录或筛选侧栏。

## 1. 结构与尺寸

| 区域 | 规格 | 来源 |

| 滚动容器 | 侧导整体随浏览器 / 产品壳高度约束；内容过长时整体滚动，滚动条不作为可见操作控件 | 产品壳侧导标准规则 |

侧导航宽度不随页面宽度变化。桌面端最小宽度仍是 `1280px`；小于该宽度时产品壳横向滚动，不压缩导航。

侧导与右侧内容面板从顶部导航下方 `82px` 开始；顶导氛围层如有延展，只作为它们的底层背景，不把侧导或内容面板整体下推。堆叠关系由 Layout Foundation 统一定义。

## 2. 状态与交互

| 状态 | 触发 | 侧导 | 内容区 |
|---|---|---|---|
| Normal | 默认、点击收起或鼠标离开 Overlay | `30px` 紧凑态，无自身投影 | 使用完整宽度，内容面板带左向 D2 投影 |
| Overlay | 鼠标进入紧凑态侧导区域 | 临时展开至 `220px`，带右向 D4 投影 | 不变，侧导覆盖内容 |
| Docked | 点击锁定按钮 | 固定 `220px`，无自身投影 | 使用剩余宽度，内容面板带左向 D2 投影 |

- Normal 显示展开图标；鼠标进入整条紧凑态侧栏即进入 Overlay。展开图标仍显示“展开”提示，并保留键盘焦点与点击入口作为补充。
- Overlay 的锁定按钮点击后进入 Docked，并替换为收起按钮；锁定按钮 hover 提示为“锁定”。
- Docked 的收起按钮点击后回到 Normal；收起按钮默认中性，hover / 按下使用绿色，hover 提示为“收起”。
- Normal / Docked 时，侧导本身不使用投影；右侧内容面板使用左向 `D2`，表达内容层覆盖在侧导边界之上。
- 未锁定 Overlay 在右侧使用 `D4` 投影，表达浮层覆盖内容；此时内容面板不再重复使用左向投影。
- 二级模块可独立展开 / 收起三级模块；多个分组可以同时展开，不是手风琴。
- 单层带图标侧导不出现虚拟父级、二级模块或展开箭头；功能项直接平铺。展开态显示 `20px` 图标 + 文案，项间距 `4px`；紧凑态宽 `56px`，只显示 `20px` 图标，选中块为 `40 × 36px`，项间距 `16px`。
- 二级带图标分组侧导用于“数据接入”等有虚拟二级模块的场景：二级模块带 `20px` 图标与展开箭头，虚拟二级内容起点距离侧导左边界 `12px`；三级模块是实际页面入口且不带图标，内容起点距离侧导左边界 `34px`；该场景替代旧的无图标分组默认展示。
- 分析专属侧导用于“分析”大功能：虚拟层级带 `20px` `sa-*` 侧导专用图标，具体分析项带 `20px` 业务面性图标；展开态同时展示层级图标与具体功能图标。虚拟二级内容起点距离侧导左边界 `12px`，三级落地页内容起点距离侧导左边界 `34px`。
- 分析专属侧导收起后只展示具体分析项图标，不展示“行为分析 / 用户分析 / 其他”等虚拟层级图标。用户点击紧凑态具体分析项图标时，具体分析项成为选中项，并进入 Overlay 展开态。
- 当浏览器或产品壳高度不足以展示完整侧导时，滚动发生在侧导整体，而不是仅菜单列表局部；标题区、分组和菜单项保持同一滚动上下文。
- 滚动条不作为可见操作控件：Firefox / 旧 Edge / WebKit 浏览器均需隐藏系统滚动条，但保留滚轮与触控板滚动能力。
- 展开不等于选中：二级模块和“更多推荐”仅因展开 / 收起时，文字、箭头与链接图标都保持默认中性颜色。
- 只有直接三级模块被选中时，其父级二级模块或“更多推荐”的文字、箭头与链接图标才使用绿色选中态。
- 三级模块有默认、悬停、点击、选中状态；选中项由页面路由或产品状态决定。

## 3. 颜色映射

| 元素 | Token / Helper |
|---|---|
| 整体背景 | `getThemeSideBackground()` / `theme-side-background` |
| 二级默认文案 | `theme-side-subText` |
| 三级默认文案 | `theme-side-text` |
| 选中文字 | `theme-side-text-active` |
| 默认 / 辅助图标 | `theme-side-icon` / `theme-side-subIcon` |
| 选中图标 | `theme-side-icon-active` |
| 目录 hover / click / selected | `theme-side-background-hover/click/active` |
| Normal / Docked 内容面板左侧投影 | `buildShadow("D2", "left")` |
| 未锁定 Overlay 右侧投影 | `buildShadow("D4", "right")` |

目录默认背景保持透明，承接侧导航渐变背景；不得用 `component-primary` 或 Functional Skin 推导选中态。

## 4. 图标

侧导航图标进入 Icon Foundation 的 `navigation` 分类：

- `side-nav-down` / `side-nav-up`：二级模块展开收起。
- `side-nav-link`：更多推荐。
- `side-nav-expand` / `side-nav-collapse`：紧凑态展开与 Docked 收起，成对使用。
- `side-nav-unpin`：Overlay 中锁定入口。
- `side-nav-pin`：锁定状态图标资产。
- `sbp-setting` / `sbp-member` / `sbp-role`：项目设置类单层侧导功能项图标，来源分别为 Figma `18354:71233` / `18354:71253` / `18354:71275`。
- `sdi-warehousing-data-ingestion` / `sdh-warehousing-general-data-ingestion` / `sdh-data-model-user-entity-manage` / `sdh-entity-conf` / `sdg-dataquality`：数据接入类二级虚拟分组图标，来源为 Figma `18596:105388` 对应组件。
- `sa-behavioranalysis` / `sa-useranalysis` / `sa-businessanalysis` / `sa-other`：分析专属侧导虚拟二级图标，来源为 Figma `18527:121296` / `18527:121302` / `18535:100610` / `1724:111294`。
- `analysis-event` / `analysis-retention` / `analysis-funnel` / `analysis-distribution` / `analysis-ltv` / `analysis-session` / `analysis-user-path` / `analysis-web-page-thermal` / `analysis-app-click` / `analysis-interval` / `analysis-attribution` 等：分析专属侧导具体功能项图标，来源为 Figma `18540:99716` 对应组件。

标题区控制图标统一按 `20 × 20px` 展示；默认颜色使用 `theme-side-icon`，hover / 按下使用 `theme-side-icon-active`。SVG 必须使用 `currentColor`；颜色由 `theme-side-*` 在组件调用处传入。

单层功能项图标也统一按 `20 × 20px` 展示；默认颜色使用 `theme-side-icon`，选中项使用 `theme-side-icon-active`。这些图标是侧导场景资产，不上升为通用功能图标。

二级虚拟分组图标统一按 `20 × 20px` 展示；默认颜色使用 `theme-side-subIcon`，当任一三级落地页选中时，父级图标、文字和箭头统一使用 `theme-side-*-active`。

分析专属侧导的具体功能项图标统一按 `20 × 20px` 展示；默认颜色使用 `theme-side-icon`，选中项使用 `theme-side-icon-active`。这些图标消费 Icon Foundation 的面性图标资产，但在侧导里只作为导航语义使用。

## 5. 边界

- 产品壳侧导可以使用 Navigation Theme；页面内锚点、目录等 Context Side Panel 不自动复用它的颜色。
- 侧导负责模块和菜单层级，不负责页面内容的列数。内容区宽度变化后由 Layout / Grid 重新组织。
- 不在侧导航组件中手写内侧阴影；内容面板与 Overlay 侧导分别通过方向型 D4 helper 承接投影。
