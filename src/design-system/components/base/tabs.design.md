# 标签页 Tabs · 设计规范（给设计师）

> 这份讲"用什么、为什么、规格多少"，面向设计与评审。
> "用 antd 怎么实现"见研发文档 `tabs.md`，本文不涉及代码/组件名。

## 什么时候用标签页
在同一**页面/模块**内，把**同层级**的多个标题聚拢展示。原则：
- **同层级**：一组标签页彼此是平级的。
- **彼此互斥**：每个标签页管辖的内容（信息/操作/状态）应当互斥。
- **禁忌**：强烈不建议在「编辑/创建」场景用标签页——它有"并立"的语义，提交时会让对象/信息显得不准确。

## 三种类型（按场景选，这是选型核心）
| 类型 | 用在哪 |
|---|---|
| 基础标签页 | 页面级同层级内容折叠，最常见 |
| 页签标签页 | 卡片级、像浏览器/编辑窗口那样可增删的标签 |
| 胶囊标签页 | 编辑器里切换面板（如 通用/高级/策略）。**胶囊标签页不是按钮** |

## 通用交互原则
- 切换标签页：默认**保留**浏览状态（分页/筛选/位置）；默认**放弃**编辑状态。
- 不支持点击"当前所在"的标签页来刷新内容。

## 各类型规格
**基础标签页**
- 一组至少 2 个标题（特殊权限场景可只 1 个）。
- 标题不可折行，建议 ≤8 个中文字（128px），超出「…」省略 + 悬停 tooltip。
- 选中项：绿色文字 + 底部高亮条滑到当前位置。
- 标题可搭配徽标强调变化。
- 标签过多：最右加「全部」，点开展示全部并定位到当前。

**页签标签页**
- 构成：标题 + 删除/关闭 + 添加 + 槽位。
- 双击任意页签标题可进入编辑、可拖拽排序、可设数量上限；只剩 1 个时隐藏删除。
- 标题 ≤8 中文字，超出省略。过多时折叠为下拉并定位当前；当前项在下拉中使用单选语义高亮并显示勾选。
- 标签过多：最右显示「更多」箭头；点击后在箭头下方偏左展开固定 `188px` 的下拉菜单，列出当前整组页签，当前项在菜单中高亮。
- 细则见下方「页签标签页 · 编辑 / 拖拽」；页签增删、更多、内容缝合和拖拽排序均属于该组件能力。

### 页签标签页 · 编辑 / 拖拽

> 双击页签标题时，该页签先成为当前项再进入编辑；可拖拽任意「页签」排序。

**编辑标题**
- 双击任意页签标题时，该页签先成为当前项，随后进入编辑。
- 悬停「当前页签」标题：出现提示「双击编辑/按住拖动排序」。
- 悬停其他页签标题：出现提示「按住拖拽排序」。
- 双击后先出现一拍 `编辑前` 选区：`component-primary` 绿底 + `white` 字；随后进入编辑态。
- 进入 `编辑中` 后：指针单击出现光标，可输入；输入文字使用正文色。
- 失焦即保存；异常时放弃本次修改（不写回错误值）。
- Esc 取消本次修改（与失焦保存并列的退出路径）。
- `Delete` / `Backspace` 不作为删页签捷径；只在输入框内保留删字含义。

**过长标题 Tooltip**
- 悬停名称过长的「其他页签 / 当前页签」标题：展示完整标题（深色 tooltip）。
- 进入拖拽按下时，相关 tooltip 立即消失。

**拖拽排序**
- 悬停「其他页签」标题：提示「按住拖拽排序」。
- 鼠标按下开始拖拽时：tooltip 消失，并**默认选中被拖拽的页签**（该页签成为当前项）。
- 换位阈值：拖拽「X 轴位移」超过相邻「页签」宽度的一半时，相邻页签向拖拽的**反方向**滑动让位。
- 可拖拽任意页签（不限当前项）；松手后落位为新顺序。
- 鼠标态：悬停可拖与拖拽中均按 SensD「移动」规则，实现为系统 **`move`**，不用 `grab` / `grabbing`。见 `docs/foundations/cursor.md`。

**胶囊标签页**
- 常规使用建议 ≤5 项；预览中的 10 项仅用于溢出、缩放和禁用态验收。每项 ≤112px，超长截断 + 悬停 tooltip。
- 选中：白底 + 轻投影 + 绿字；选中悬停字色为 hover 绿。
- 未选中悬停：标签带的连续灰底保持不变，单项不换背景，文字切功能绿。
- 未选中点击：标签带的连续灰底保持不变，单项不换背景，文字切 active 深绿。
- 禁用：标签带的连续灰底保持不变，单项不换背景；文字与徽标降到禁用层级，禁用悬停只切换到更弱一档文字层级。
- **只能独立使用**，不允许和其它标签页搭配来表达层级。
