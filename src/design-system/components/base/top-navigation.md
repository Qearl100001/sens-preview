## Product Shell 关系

- 顶部导航是 Product Shell 的上层产品导航；与侧边导航、标题栏、内容面板的组合关系见 `../composite/product-shell.md`。
- 样板间或真实业务页使用顶导时，应调用 `SensTopNavigation` 或 Product Shell 组合，不得复制一套局部顶导壳。
- 一级导航项与下拉 IA 的唯一源为 `product-shell-nav-catalog`；基础组件页与 `/templates/product-shell` 共用该目录派生的默认配置，禁止在组件内另写业务扁平菜单。
- 顶部导航决定当前产品 / 项目 / 一级功能域；侧边导航展示当前一级功能域内页面目录；标题栏只表达当前落地页身份。
- 固定高度产品壳中，内容区滚动超过阈值后顶导（含氛围）可整体收起；规则与验收入口见 `../composite/product-shell.md` §5 与 `/templates/product-shell`。

## 关键规则

1. 顶部导航是产品壳专属组件，不复用为普通 `Dropdown` / `Menu`。
2. 顶导航背景、文字、图标、分隔线和选中短线全部消费 Navigation Color 语义；不得回退为普通 `component-*`、`text-*` 或 `link-*` 色。
3. 主导航选中只显示文字下方短线，不使用整项背景。
4. 产品切换、账号角色属于上下文浮层，可与业务导航浮层并存；第二行主导航与「更多」属于同一组业务入口，同一时间只允许打开一个。
5. 九宫格功能入口是快捷定位入口，不作为独立选中来源；在九宫格中选择功能后，应同步定位到对应的第二行业务导航分类，并在该分类下拉内保留 leaf 选中态。
6. 右上角功能图标与第二行全部业务入口的选中态互斥；收进「更多」的入口仍属于第二行，不回填选中右上角图标。
7. 顶导宽度始终跟随容器 / 浏览器拉伸，不以 `1280px` 画布锁死；组件内不做横向滚动。上导航左簇（Logo + 项目）与右簇（工具 + 账号）最小间距 `spacing/4x`（16）；到达该间距后不再继续变窄（内容量宽为下限）。
8. 「更多」永远最右；空间不足时从右往左将主导航收入「更多」L1，不升为全局固定断点规则。
9. 顶导实际结构高度为 `82px`。设计稿需要产品壳氛围时，可显式开启 `atmosphere`，延展至 `180px` 的视觉背景层；该层不占正文流。
10. 页面接入顶导后，侧导与右侧内容面板仍从顶部 `82px` 开始覆盖在氛围层之上；具体堆叠关系由 Layout 维护。
11. 顶导浮层属于产品壳全局浮层，必须压在标题栏、侧导、右侧内容面板和内容容器之上，不得被页面或样板间局部容器遮盖、裁切。

| 项 | 来源 | 说明 |

| 圆角与投影 | Radius / Shadow Foundation | 浮层 `radius/m` · `buildShadowD4` |
| 字号 / 字重 / 行高 | Typography Foundation | 下导 `l`；项目名 `m`；账号名 `l`·semibold；角色 `s` |
| 间距 | Spacing Foundation | 水平 `4x`；Logo↔项目 `6x`；工具 `4x`；下导项 `2x`/`4x`；上栏簇间距下限 `4x` |
| 功能入口彩色标签 | `SensTag` multicolor | hot→旭日红 / new→冰绽蓝；不进 Navigation Color |

| 角色 pill 圆角 / 竖直 pad | 组件结构常量 `12` / `3` | **不升** foundation（不为单场景加 `radius/12`） |
| 两层菜单单条宽 / 列间距 | 组件结构常量 `193` / `7` | **不升** foundation spacing（`7` 仅顶导） |
| 项目切换列表遮罩 | 组件结构常量 | 白色渐变遮罩来自 Figma 固定效果，仅服务项目切换面板末项遮罩；不升为通用颜色 token |

## 结构常量边界

`220`、`294 / 296`、`193`、`7`、`36`、`40`、`46`、`82`、`120` 等当前只作为顶部导航或产品壳组合里的结构常量记录。它们暂不升为 Foundation，也不作为通用组件尺寸规则；只有当后续多个组件 / 多个页面稳定复用同一语义时，再回写到对应 Foundation。

## 验收

- `/components/top-navigation`：主导航选中短线、功能入口、项目切换和账号角色浮层互斥；氛围层开启时验证其不推移正文。
- 切换导航主题后：顶导航背景、文字、图标、线条与菜单色同步变化；普通页面内容保持 Neutral Foundation。
