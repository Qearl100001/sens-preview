# 视图切换 View Switch · 设计规范

> 一种用于特殊场景的异形单选组件，主要用于切换同一组数据的视角或模块布局。
> 来源：Sens.Design 视图切换 v2.1（2023-04-20）；Figma 视觉样式与业务实例见下方链接。

## 使用场景

- 用于在同一组数据间切换不同视角，例如柱状图 / 条形图 / 折线图，或平铺 / 目录视图。
- 将控件放在被控制模块操作区的右上区域；不要把它当作页面主导航或跨页面标签页。
- 一组支持 2–6 个选项，建议优先控制在 2–3 个；超过 6 个视角时使用选择器。

## 内容与交互

- 优先使用「图标 + 文字」，纯文字也可使用。
- 纯图标仅用于空间受限场景，每个选项必须提供 Sens Tips 和无障碍名称。
- 选项互斥，默认应有一个视角处于选中态；切换只改变当前模块视角，不隐含数据刷新、导航或编辑状态处理。
- 禁用项仍可见、不可切换；禁用悬停不恢复可交互反馈。

## 视觉规格

- 控件高度 32px；正文 14px / 22px；图标 16px，图标与文字间距 4px，左右内边距 12px。
- 作为连续分段组呈现：首项左侧圆角 4px、末项右侧圆角 4px，中间接缝不重复加粗。
- 默认选中项使用功能色边框、文字与浅色背景。悬停、点击、禁用及选中态沿用单选控件状态语义。
