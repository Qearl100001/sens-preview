## 录入结论

便签作为**基础组件**单独录入，英文名 Tips。P0 只做**常规便签**（纯文案 + 箭头）。  
「高级便签」按产品确认归属**业务组件**，不写入基础组件实现与预览。

## Figma 提取摘要

- 非稳定模态；对特定对象做「非强调但不可少」说明；主交互为悬停。
- 原则上只承载纯文案；关键必读信息不宜只靠便签。
- 设计原则：应有尽有；招之即来、挥之即去；指向明确、描述准确。
- 类型二分：常规 / 高级（高级不进基础）。
- 悬停 **0.1s** 后出现；离开立即消失；点击便签无反馈。
- UI：背景 `tooltip-background`；白字 14/22；水平 pad 10、垂直 pad 6；圆角 4；最大宽 **300**（不足随文案变窄，横向排版）；最高 **10.5 行**超出内滚；与触发源间距 4。
- 最大宽 / 最大高样张：Figma `6613:32568`（满宽）、`6613:32687`（满宽&高 + 滚动条）。
- 滚动条：拇指宽 6、圆角 `radius/s`、色 `tokenRgba(white, 0.8)`（对应稿面象牙白/07 语义）。
- 常规中置箭头：Figma `1172:218` 软肩三角 path（viewBox 16×6）；侧向旋转后视觉约 **6 × 16**，上下 **16 × 6**。P0 用 **inline SVG path + currentColor**（不落 raster）；矩阵静态样张用 `strategy="anchored"`，避免文档栏布局变化后 portal 坐标跑偏。
- **12 向箭头位置**（组件效果 `1148:109`–`164`）：`placement` × `align`。上下边对齐槽宽 **28**（两侧各 6 + 三角 16，尖端距边 14）；左右边对齐槽高 **22**（角侧 6 + 三角 16，尖端距边 14，左上/左下/右上/右下均不与气泡顶底相连）。矩阵展示上左…右下共 12 格。
- **自动避让（P1）**：仅 `portal`；先试传入 `placement`，装不下再按上 → 左 → 右 → 下；`autoAdjust` 默认 true，矩阵 `anchored` 忽略。
- **宽触发源（P1）**：宽 ≥300 时按指针在触发源前/中/后 1/3 推导 `align`；无指针（键盘聚焦）回退 prop。
- 文案可选中/复制时，触发源与便签热区必须连通，鼠标可以从触发源移入便签区域。

## 设计边界

- 常规便签 = 深色气泡 + 三角指向，不换肤。
- 不与 Message / Alert 混用场景。
- 多便签碰撞时不允许同时展示；优先级：禁用原因+建议 > 截断说明 > 操作引导（调用方保证）。
- 箭头尺寸为组件契约，不升全局 token；后续若多个浮层组件共用同样箭头，再抽内部 helper/token。
- 常规便签只做纯文案；高级便签、自动稳定展示、复杂内容卡片后置为业务/复合能力。
