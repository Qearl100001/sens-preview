# 卡片 Card · 设计规范（给设计师）

> Card 是承载内容的基础容器，不等同于入口卡片、数据源卡片等业务卡片。
> 真实交互与状态可在 `/components/card` 走查；基础尺寸和 token 对照见 `/basic-styles/card`。

## 什么时候用卡片

卡片用于把一组相关内容收纳在一个清晰的承载边界内。它可以承载自由内容、标题区、内容区和操作区，但不规定具体业务字段。

不要因为一个区域有白底或圆角，就自动把它定义为 Card。页面背景、标题栏、表格容器和浮层应优先使用各自的页面或组件规则。

## 基础类型

| 类型 | 使用场景 | 视觉表达 |
|---|---|---|
| 描边卡片 | 普通内容容器、信息面板、业务区块 | 白底 + 浅描边 |
| 色块卡片 | 弱层级区块、轻量承载区域 | 灰色透明背景 + 无描边 |

卡片不限制固定宽高：宽度由外部布局、栅格和页面容器决定，高度由内容自然撑开。

## 容器规格

- 内边距：`spacing/4x`，16px。
- 圆角：`radius/l`，6px。
- 标题区、内容区和操作区是否存在，由具体组合场景决定。
- 标题区可以使用图标、标题和操作，但不是所有 Card 的强制结构。

## 交互状态

### 通用卡片状态样张

通用卡片是 `SensCard` 的最小状态示例，不另设一个业务组件。组件页展示以下七种状态：

| 状态 | 视觉规则 |
|---|---|
| 默认 | 白底、浅描边、无投影 |
| 悬停 | 白底、浅描边、D3 向下投影 |
| 点击 | 功能色 active 描边和激活外环 |
| 选中 | 功能色 active 描边；不自动附带业务选择语义 |
| 选中悬停 | 选中描边叠加 D3 向下投影 |
| 禁用 | 中性浅底、浅描边、禁用内容层级 |
| 禁用悬停 | 禁用内容层级不变，可保留 D3 向下投影 |

该样张使用 `spacing/3x = 12px` 内边距和 `radius/l = 6px` 圆角。12px 只属于该组合示例，不新增全局 Card padding token。真实业务选择仍由宿主组合 `SensCheckbox`、`role` 和 `aria-checked`。

### 普通交互卡片

可交互卡片使用 default / hover / pressed 三种状态：

- default：白底、浅描边、无投影。
- hover：保持白底和描边，增加 D3 向下投影。
- pressed：使用功能色 active 描边和激活外环。

普通自由卡片和网格视图卡片共用这套容器交互规则。

### 操作外露型卡片 / 无选择功能

当卡片只能承载操作、不能被选中时：

- 卡片不定义 `selected` / `checked`，不使用 checkbox，也不承担选择语义。
- 操作 1、操作 2 使用弱化链接按钮；默认使用 `text-color-transparent`，标准尺寸为 14 / 22 / 400，悬停和点击进入链接色。
- “更多”使用弱化链接按钮作为下拉触发器，菜单项使用链接菜单行，并通过点击展开。
- 右上角更多图标是可聚焦、可点击的纯图标按钮，打开同类更多操作菜单。
- 操作按钮不添加装饰性图标；下拉箭头只属于“更多”触发器。
- 卡片悬停可以提升操作文案的链接强调，但不因此产生选中态。
- 该场景只保留 hover，不产生 pressed / 激活外环；实现时使用 `SensCard interactive pressable={false}`。
- 卡片宽度由外部布局、栅格和页面容器决定，不能在组件场景中设置固定最大宽度。

该场景的真实交互位于 `/components/card` 的“网格视图卡片 / 操作外露型 / 无选择功能”示例中。

### 选择型卡片

只有带 checkbox 的选择型卡片使用 selected / checked：

- 使用功能色 active 描边。
- 使用功能色浅背景。
- 使用功能色 active 外环表达激活状态。
- 悬停时保留 active 背景和描边，并复用普通网格视图卡片的 D3 向下投影。
- 选择框复用 `SensCheckbox` 的 control-only 视觉，选中颜色、勾选图标和 hover / active 颜色跟随 Checkbox 组件。
- 操作 1、操作 2 和“更多”复用网格视图卡片操作外露型规则：默认弱化，每个按钮只在自身悬停 / 点击时变为链接色；菜单打开时对应的“更多”触发器保持链接色，其他按钮不被连带高亮。
- 底部“更多”和右上角更多图标均可点击打开链接菜单。

普通 Card 不定义 selected 状态。

### 禁用和报错

- disabled：灰背景、浅描边、禁用文字。
- disabled hover：保持禁用内容层级，可保留 D3 投影用于对照。
- error：警告浅背景、警告描边；警告说明放在卡片外部或内容区下方。
- 禁用状态中的操作控件必须使用真实 `SensButton disabled` / `SensButtonActionMenu disabled`，不可用静态文字替代。

## 组合边界

Card 只负责基础容器，不负责：

- EntryCard / DataSourceCard 等业务字段结构。
- 卡片列表布局、网格列数和响应式策略。
- 标题区固定布局。
- 拖拽、排序和复杂选择逻辑。
- 操作外露型卡片的业务动作和菜单项内容。

这些能力由复合组件、业务组件或页面宿主负责。
