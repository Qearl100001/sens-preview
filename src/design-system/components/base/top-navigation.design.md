# 顶部导航 Top Navigation · 设计规则

> 面向设计选型与评审；实现映射见 `top-navigation.md`。

## 什么时候用

顶部导航用于产品壳的全局入口、一级导航、项目上下文和账户入口。它始终位于页面标题栏之上，不替代页面级 TitleBar。

顶导实际结构高度为 `82px`。设计稿出现产品壳氛围时，可在其下延展至 `180px` 的背景层；侧导和右侧内容面板仍从顶部 `82px` 起叠放在该背景之上，氛围层不占正文流。完整层级关系见 `Layout Foundation`。

## 设计原则

| 原则 | 规则 |
| --- | --- |
| 结构稳定 | 上导航承担全局工具与上下文；下导航承担功能入口与主导航，不能混放 |
| 选中克制 | 主导航选中使用文字下方短线，不用整项背景抢占内容层级 |
| 浮层专属 | 项目、账号和主导航的展开内容属于产品壳浮层，不套用普通业务下拉菜单；账号 / 项目上下文浮层可与业务导航浮层并存；所有顶导浮层都必须位于标题栏和内容面板之上 |
| 换肤可控 | 只替换导航色系；普通内容区、表格、表单保持中性基础色 |
| 氛围可选 | 只有设计稿需要时开启顶导氛围层；它是产品壳背景，不是页面顶部留白 |

## 推荐

- 主导航文案短且清晰，按产品信息架构排序。
- 第二行业务入口（主导航与「更多」）同一时刻只展开一个；右上角功能图标与第二行入口的选中态互斥。账号 / 项目上下文浮层不纳入这组互斥规则。
- 九宫格功能入口是快捷定位入口，不作为独立选中来源；在九宫格中选择功能后，应同步定位到对应的第二行业务导航分类，并在该分类下拉内保留 leaf 选中态。
- 两级业务菜单的已选子项使用与一级菜单相同的选中底色、文字色和 `aria-current`；子项选择只改变菜单内部状态，分类触发器仍显示“分析 / 智能运营”等一级名称。「更多」是例外，选中的叶子会回填触发器文案。
- “正式项目”触发器只负责项目切换浮层；项目切换使用悬停打开，点击项目名不负责打开或切换浮层，也不得复用账号 / 个人设置浮层。
- 顶导主浮层（项目切换、九宫格功能入口、账号菜单、主导航下拉、更多）在离开触发器与浮层后约 `120ms` 收起；重新进入任一侧会取消收起，保证从触发器移动到浮层时不闪退。账号内部「系统语言 / 诊断工具」下钻为悬停立即展开，悬停其他账号项时立即切换或收起，不套主浮层延迟。
- 顶导浮层是产品壳全局浮层，不是样板间或页面局部浮层；不能被标题栏、侧导、内容面板、卡片、表格或内容容器遮盖 / 裁切。
- 通过导航主题表达产品壳层级，不把功能色扩散到普通内容区。
- 设计稿有氛围层时，验证内容面板仍从 `82px` 顶导下方开始，而不是从 `180px` 后开始。

## 禁止

- 不把顶部导航、页面标题栏和侧边导航合并成一个组件。
- 不为主导航选中态增加整块背景。
- 不以固定像素阈值猜测“更多”收纳规则。
- 不把顶导锁成 `1280px` 画布或组件内横向滚动；流体宽 + 上栏左右簇最小间距 `spacing/4x`。

## 验收

- `/components/top-navigation`：层级、选中态、浮层和换肤表现。
- `/basic-styles/navigation-color`：顶部导航色系与标题栏、侧导航、页面背景的映射关系。
