## 边界

负责文件选择、可选拖拽接收、文件列表/图片格呈现，以及上传状态、只读、禁用、必填错误展示。业务层负责服务端传输、模板下载、格式与内容校验、大小限制和业务错误决策。

## 核心规则

- 一个 `SensUpload` 通过 `mode="file" | "image"` 提供两种视觉呈现，不拆成两个组件。
- `dragEnabled` 开启拖拽；文件/图片呈现共享 `files` 与 `onChange` 数据契约。
- 上传数量上限由业务通过 `maxCount` 传入，组件不定义统一固定上限；未传 `maxCount` 时多文件模式不限制数量，`multiple={false}` 仍只接收一个文件。组件负责达到业务上限后的入口呈现、禁用和说明，不替业务决定上限值。
- 文件项 `status` 支持 `uploading`、`done`、`error`；未设置 `status` 表示文件已被本地选择、但组件不声明服务端传输结果，视觉上按普通已选文件呈现。调用方接入真实传输后负责设置并更新状态；`uploadedSize` / `percent` 驱动已上传大小与进度显示，`onCancel`、`onRetry`、`onDownload` 由调用方接入。
- 文件上传模式宽度固定为 432px，窄容器内不得溢出；文件列表、顶部入口和拖拽投放区与组件同宽。图片模式的 80×80 方形上传入口和图片格不受该宽度约束。
- 错误项通过 `errorMessage` 显示大小/格式/传输错误；仅传入 `retryLabel: "续传" | "重试"` 时展示对应操作，不传则只保留删除。
- 文件列表状态按 Figma 展示：完成态紧凑单行；上传中、失败态分为名称行与缩进详情行；失败条目保留红色进度，调用方以 `percent` 提供中断位置，未提供时按完整失败条显示。上传中“取消”入口悬停/聚焦时使用上方提示“取消上传文件”。
- 文件名过长时采用中间省略，尽量保留文件名前段和末段，并完整展示扩展名；悬停显示完整文件名。
- 文件样式只提供顶部“上传文件”入口，不显示底部重复的“继续上传”链接或文件数量角标；业务传入 `maxCount` 后组件按此限制可添加数量，但不显示计数。达到业务上限时，可见的上传按钮/拖拽入口置灰，悬停时提示“最多可上传 N 个文件”（N 为业务传入值；未传时不显示上限提示，单文件模式仍最多 1 个）；组件手动禁用时不显示此数量提示。
- 完成态图片文件在有 `url` 时显示 58×58 缩略图；只读图片保留缩略图，上传中/失败图片仍以附件图标呈现。用户通过文件选择器选择图片时生成浏览器本地预览地址；该预览不表示服务端已完成上传。
- 图片上传入口实现 Figma 九态：默认、悬停、按下、禁用、禁用悬停、加载中（加载环和“取消”）、必填错误、必填错误悬停、必填错误按下。禁用入口保留可见但不可打开选择器；图片模式必填错误在入口内显示“请上传”，不重复显示外置错误信息。
- 图片项处于 `uploading` 时显示加载环与小尺寸 `linkWeak` “取消”；悬停/聚焦取消入口时通过 `SensTips` 在上方提示“取消上传文件”，实际任务取消由调用方传入 `onCancel` 处理。`disabled` 或 `readOnly` 时取消入口隐藏且不会调用 `onCancel`。达到 `maxCount` 后仍隐藏新增入口，`readOnly` 不显示可编辑入口。
- 图片已上传项实现 Figma 六态：完成/只读显示实际图片缩略图；`error` + `retryLabel: "续传"` 显示环形状态图标和“上传失败”；`error` + `retryLabel: "重试"` 显示错误图标和“上传失败”；图片过大与格式错误显示对应警告文案。数量限制仍由 `maxCount` 执行，但不展示图片数量角标。
- 图片已上传项悬停覆盖 Figma 六态：完成态预览/删除、只读态仅预览、续传/重试失败显示对应操作/删除、图片过大与格式错误仅删除。遮罩使用 `mask-01-transparent`，操作图标间距为 `spacing/4x`；键盘聚焦时显示相同操作层。图片操作图标默认白色；预览/续传/重试悬停和按下分别使用链接蓝 `link-color` / `link-active-color`，删除悬停和按下分别使用 `warning-color-hover` / `warning-color-active`（Figma `16835:60899`）。
- 图片预览行为通过 `onPreview(file)` 交给调用方；`/components/upload` Demo 实现 Figma 查看层（`7869:1630`）及轮播说明（`7869:3289`）：关闭、键盘 Escape、选中缩略图、左右按组翻页、计数和当前项高亮。缩略条最多同时呈现四张图；此“四张可见”是预览布局规则，不是上传数量上限。大图随视口宽度自适应并左右各留 60px，高度按原图比例缩放；图片与上传时间信息间距为 `spacing/1x`（8px）。缩略图和左右切换控件距视口底部 60px，计数显示在轮播下方并保持 `spacing/1x`（8px）间距；大图与轮播间距动态伸缩，短视口时按比例缩小大图。实际产品的图片信息/时间文案由业务提供。
- 文件样式在 `mode="file"`、`dragEnabled`、`multiple={false}` 时启用单文件拖拽呈现：默认/悬停/点击拖拽中、禁用/禁用悬停、上传中、完成/完成悬停、只读/只读悬停、失败续传/重试、必填错误/悬停/点击拖拽中共十五态。设计拖拽区最大宽度 432px、高 104px；上传完成后以大图替代投放区，悬停可预览/删除，只读仅可预览；上传中和失败呈现进度及相应操作；取消入口悬停/聚焦时提示“取消上传文件”。单文件已存在时不再显示第二个上传入口，删除后恢复入口。
- 文件和图片两种样式均支持 `dragEnabled` 多文件拖拽。编辑态均在列表上方显示 432×104 大投放区；文件样式下方为文件行，图片样式下方为 80×80 缩略图行；只读态隐藏投放区，仅展示已有文件/图片。图片拖拽模式不额外显示缩略图上传格，非拖拽图片模式仍将上传格排在图片项之后（Figma 六态见本文来源）。
- 多图片按 `files` 顺序排列，上传图片入口排在所有已上传项之后（Figma `16830:58360`、`16830:58363`）。
- 只读项可通过 `onDownload` 提供下载操作；只读不开放删除、重试或取消。禁用态同样不提供会修改上传任务的取消、重试、删除操作。
- 文件列表文字操作复用小尺寸 `SensButton` 并设置 `restingColorToken="link-color"`：删除使用 `dangerLinkWeak`（默认链接蓝，悬停警告红）；取消、下载、续传和重试使用 `linkWeak`（默认链接蓝，悬停保持链接蓝）。图片缩略格上的图标操作不受此规则影响。
- `disabled` 禁用整个组件；`readOnly` 保留内容但不提供修改操作。达到 `maxCount` 时，文件样式保留顶部入口并禁用且说明上限原因；图片普通模式隐藏新增入口，已有可见拖拽入口显示相同上限提示。
- `showFileControls` 默认显示文件选择入口；用于展示单个文件状态时可关闭，避免把场景级入口混入状态卡片。
- 不接收内容校验、模板下载或真实网络传输逻辑。

## 缺口与待确认

- 首轮规则没有限定默认文件大小和可接受格式，交由调用方设置。
- 上传进度与服务端失败/重试完全由业务接入；本地选择的文件不会被组件标记为服务端上传成功。
- Preview 中的进度推进只是回调演示；生产上传的续传位置、网络进度、完成/失败状态仍由调用方更新 `files`，组件不模拟真实传输。
- Figma 八页中的场景帮助文案和单文件重新上传用词由调用方按业务配置。
- 真实网络传输、断点续传和服务端错误恢复不属于 Prototype Kit；p0.9 只发布组件外观、状态与回调契约。
