## 边界

负责文件选择、可选拖拽接收、文件列表/图片格呈现，以及上传状态、只读、禁用、必填错误展示。业务层负责服务端传输、模板下载、格式与内容校验、大小限制和业务错误决策。

## 核心规则

- 一个 `SensUpload` 通过 `mode="file" | "image"` 提供两种视觉呈现，不拆成两个组件。
- `dragEnabled` 开启拖拽；文件/图片呈现共享 `files` 与 `onChange` 数据契约。
- 文件项 `status` 支持 `uploading`、`done`、`error`；`uploadedSize` / `percent` 驱动已上传大小与进度显示，`onCancel`、`onRetry`、`onDownload` 由调用方接入。
- 错误项通过 `errorMessage` 显示大小/格式/传输错误；仅传入 `retryLabel: "续传" | "重试"` 时展示对应操作，不传则只保留删除。
- 文件列表状态按 Figma 展示：完成态紧凑单行；上传中、失败态分为名称行与缩进详情行；失败条目保留红色进度，调用方以 `percent` 提供中断位置，未提供时按完整失败条显示。
- 只读项可通过 `onDownload` 提供下载操作；只读不开放删除、重试或取消。
- `disabled` 禁用整个组件；`readOnly` 保留内容但不提供修改操作；`maxCount` 到达后隐藏新增入口。
- `showFileControls` 默认显示文件选择和列表后的继续上传控制；用于展示单个文件状态时可关闭，避免把场景级入口混入状态卡片。
- 不接收内容校验、模板下载或真实网络传输逻辑。

## 验收

- [ ] 文件与图片两种真实 Demo 和状态矩阵。
- [ ] 本地选择与拖拽、达到数量上限、删除、重试/预览回调。
- [x] 新增 Figma 七个文件列表状态已在 `/components/upload` 浏览器核对：完成、上传中、只读下载、失败续传、失败重试、文件过大、格式错误。
- [ ] 上传中、完成、续传/重试失败、大小/格式错误、必填错误、只读、禁用状态的完整真实交互验收。
- [ ] 1280–1920 宽度、长文件名、缩略格换行。
- [ ] TypeScript / 生产构建、Prototype Kit 打包和浏览器交互验收。

## 缺口与待确认

- 首轮规则没有限定默认文件大小和可接受格式，交由调用方设置。
- 上传进度与服务端失败/重试完全由业务接入；组件本身不伪造传输成功。
- Figma 八页中的场景帮助文案和单文件重新上传用词由调用方按业务配置。
