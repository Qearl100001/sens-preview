## 定位与边界

- Popover 是点击触发的轻量浮层，可承载浏览或局部操作；不等同于悬停说明 `SensTips`。
- 不加页面蒙层；点击触发器打开，点击卡片外或按 Escape 关闭。
- 标题可选且单行省略；内容为必要区，超高时只滚动内容区。
- 浏览型不带主导操作；操作型操作区右对齐，主操作最右，禁止把负向操作设为主操作。
- **二次确认**（`variant="confirm"`）：需轻量二次确认时用；标题带警告图标、无分割线；操作区左为危险描边（如「放弃」），右为二级按钮；仅小 / 中尺寸（`large` 回落为中）；`placement` × `align` 与普通型相同（12 向）。
- 最多两次下钻，合计不超过三层；下钻页必须提供返回。
- 使用 Sens 自持 portal 与定位，不使用 antd Popover 作为视觉或交互承载。
- portal 使用视口 `fixed` + 滚动位移补偿：打开时相对触发器算一次位置；之后随最近滚动容器滚走，滚出视口即看不见；**不**在滚动中持续贴触发器重算。

## API

```tsx
<SensPopover
  size="medium"
  placement="top"
  align="start"
  title="标题"
  content={<div>正文文案</div>}
  actions={<><SensButton tone="secondary">取消</SensButton><SensButton>确认</SensButton></>}
>
  <SensButton>打开</SensButton>
</SensPopover>
```

| 属性 | 说明 |
| --- | --- |
| `size` | `small` / `medium` / `large`，默认 `medium` |
| `variant` | `browse` / `action` / `confirm`，默认 `action`；`confirm` 为二次确认场景 |
| `placement` × `align` | 上下左右 × 起始、中间、末端，形成 12 向箭头位 |
| `title` | 可选标题；超过一行省略 |
| `content` | 必填内容区；内部超高纵向滚动 |
| `actions` | 可选操作区；由 `SensButton` 承接按钮规格与排序 |
| `open` / `defaultOpen` / `onOpenChange` | 受控与非受控显隐 |
| `autoAdjust` | 贴近视口边缘时尝试反向展开，默认开启 |
| `strategy` | `portal`（默认，业务真实定位）/ `anchored`（仅状态矩阵稳定呈现 12 个箭头位） |

## 尺寸与视觉

| 尺寸 | 宽度 | 标题 / 内容横向 padding | 内容下 padding | 操作区 |
| --- | ---: | ---: | ---: | --- |
| 小 | 360 | 16 | 16 | 56 高，`SensButton small`，间距 12 |
| 中 | 560 | 16 | 24 | 64 高，常规按钮，间距 16 |
| 大 | 720 | 24 | 24 | 64 高，右 padding 24，常规按钮，间距 16 |

- 标题 `16 / 24 / 600`；正文 `14 / 22 / 400`；圆角 6。
- 卡片使用 Figma D4 投影、白色 surface 和 token 推导的 1px 分割线。
- 卡片最大高度 **600**；短内容随内容收缩，超长时标题与操作区钉住，仅内容区纵向滚动。
- 操作栏向上投影（`buildShadow("D2", "up")`）仅在内容区 **已向下滚动**（`scrollTop > 0`）时出现；短内容或未滚动时不出现。
- 箭头资产来自 Figma；仅旋转资产以适配方向，不手绘 SVG。

## 验收

- 三种宽度、标题/内容/操作区 padding、按钮高度与间距正确。
- 点击、外部点击、Escape 均构成打开/关闭闭环；无蒙层。
- 上下左右 × 起始、中间、末端的 12 个箭头位均可查看；箭头始终指回触发器。
- 业务场景使用 portal；打开后不因滚动持续贴触发器重算；随滚动容器滚走，滚出视口即不可见。
- 浏览型不渲染操作区；操作型主操作处于最右。
- 二次确认：`feedback-warning` + `info-color`（原野黄）+ 14 标题、无分割线、正文左缩进 36；小 360 / 中 560；放弃为 `dangerSecondary`，右侧为 `secondary`；方位 12 向与普通型共用。
- 超长内容：卡片高度 ≤ 600；标题与操作区不随滚；内容区可滚且无横向滚动；小 / 中 / 大均可打开对照 `6483:35568` / `35684` / `35800`。
- 不新增 `.ant-*` 覆盖或 `!important`；颜色、阴影来自现有 token / helper。
