# 步骤条 Steps

状态：`Pilot · Implemented · Preview`
预览：`/components/steps`
来源：Sens.Design 步骤条设计文档（节点 `4686:15251`、`2580:11057`）

## 适用范围

步骤条用于展示有先后顺序的流程，并允许用户在流程允许时回到已完成步骤。当前预览实现横向步骤条，并分为无辅助文案和有辅助文案两种结构；不实现纵向变体。

## 视觉规则

- 大号：步骤编号圆 `size/component-height/m`（32px），编号与标题使用 `font-size/l` / `line-height/l`。
- 小号：步骤编号圆为 24px（`size/component-height/s`），圆角为 12px；编号与标题使用 `font-size/s` / `line-height/s`（12px / 18px），编号与标题间距为 8px。
- 辅助文案使用 `font-size/s` / `line-height/s`，标题与辅助文案间距为 `spacing/vertical/1x`（4px）。
- 无辅助文案时序号与标题同一行；有辅助文案时辅助文案独立成行，并从标题内容起点（序号 32px + 8px 间距）对齐。
- 步骤之间的连接线为 1px，连接线与步骤内容保留至少 `spacing/horizontal/2x`（8px）的呼吸空间。
- 末项不参与等分宽度（`flex: none`），贴步骤条右缘；连接线只在前序项内拉伸。否则末项格子里标题靠左、右侧留白，整条视觉中心会偏左。
- 等待态使用中性色；进行中和已完成态使用当前功能色；编号反白使用 `white`。
- 禁用态降低对比度并保持布局尺寸，不因禁用内容改变步骤条宽度。
- 加载态在序号位置显示动效 loading 图标，大号 18px、小号 16px；默认使用 `icon-color-transparent-disable`，悬停使用 `icon-color-transparent-disable-hover`，标题同步使用对应禁用文字色，不切换功能色。
- 当前项只有一个；当前项显示功能色实心序号。**仅当前项标题**使用 `font-weight/semibold`；序号、辅助文案、等待 / 已完成标题均为 `font-weight/regular`。当前项默认标题色 `text-color-transparent` @0.9；悬停标题切功能色；报错悬停切 `warning-color`。辅助文案始终中性，不跟标题换色。
- 已完成步骤的序号显示 Sens 对勾图标，不显示数字；已完成支持默认、悬停、点击三态。
- 未完成步骤支持默认、悬停、点击、加载、加载悬停、禁用、禁用悬停七态。
- 报错是叠加语义：通过 `error` 标记与等待、当前、已完成、加载生命周期组合，不改变布局；未完成报错展示 5 态，当前项报错展示 2 态，已完成报错展示 3 态。
- **红数字 vs 红对勾**：对勾只表示「这一步已经完成」。未完成（当前 / 等待）报错显示红色数字；已完成报错显示红色对勾。`error + loading` 复用普通 loading 的中性灰，不改成告警色。
- 未完成报错的悬停 / 点击：序号底与数字保持告警色（`warning-light-background` / `warning-color`），不得被等待态悬停规则换成功能色浅底。当前项报错悬停仍是告警实心底。告警色不换肤。

## 交互规则

- `current` 为受控当前步骤；未传入时使用 `defaultCurrent` 并由组件内部维护。
- 单项可通过 `status` 显式指定 `wait`、`process`、`finish` 或 `loading`；未指定时由 `current` 与 `completed` 推导。
- `completed` 表示该步是否已无错通过。`false` 时即使下标小于 `current` 也保持等待，避免未改完的报错步被自动推成已完成。未传 `completed` 时仍按 `current` 推导，兼容组件页 Demo。
- `error` 只切换告警语义色，不单独变成一种流程态。
- 分步表单里的报错时机：
  - 步骤条、下一步、上一步都能换步；下一步有错不拦截。
  - 带着错误离开：该步保持 **等待 + 报错 + 红色数字**，不得变成已完成。
  - 无错点「下一步」：该步 `completed`，序号变为绿对勾。
  - 整表最后点「提交」校验失败：已经走过的步骤若被打回，**已完成 + 报错 + 红色对勾**；若失败发生在当前最后一步，仍是当前 + 红色数字。
- `status="current"` 只允许一个步骤使用；`status="finish"` 用于已完成步骤，`status="disabled"` 用于禁用步骤。
- 只有传入 `onChange` 且步骤未禁用时，步骤项才可点击；回调返回新索引和对应项。
- 键盘操作使用原生 button 语义；禁用项不可聚焦、不可触发回调。
- 状态矩阵用于检查视觉状态，真实 Demo 用于检查点击切换和受控行为；矩阵不能替代浏览器验收。

## Token 映射

| 角色 | Token / 来源 |
| --- | --- |
| 功能色、悬停、点击 | `functionalSkin` |
| 标题、编号文字 | `text-color` |
| 辅助文案、等待态 | `text-sub-color-transparent`、`icon-color-transparent` |
| 边框 | `outline-color` |
| 已完成编号反白 | `white` |
| 报错状态 | `warning-color`、`warning-color-hover`、`warning-color-active`、`warning-light-background`、`warning-light-outline` |
| 尺寸与字号 | `size/component-height/*`、`font-size/*`、`line-height/*` |

## 验收清单

- [ ] 大号 / 小号尺寸、字号和连接线可辨识。
- [ ] 小号分别展示无辅助文案 / 有辅助文案，并覆盖默认、悬停、点击、加载、加载悬停、禁用、禁用悬停七种未完成状态。
- [ ] 等待、进行中、已完成、禁用状态颜色和连接线一致。
- [ ] 无辅助文案 / 有辅助文案两种结构分别验收，辅助文案从标题内容起点对齐。
- [ ] 加载态使用 Sens loading 图标，不显示步骤数字。
- [ ] 未完成步骤七种状态、当前项两种状态、已完成步骤三种状态分别可辨识。
- [ ] 无辅助文案 / 有辅助文案分别验收报错矩阵：未完成 5 态、当前项 2 态、已完成 3 态；未完成 / 当前报错为红色数字，已完成报错为红色对勾；加载态不改成告警色。
- [ ] 未完成报错悬停 / 点击：序号底为 `warning-light-background`，不是功能色浅底。
- [ ] 当前项只有一个，已完成项显示对勾而不是数字。
- [ ] 仅当前项标题加粗（`font-weight/semibold`）；序号、辅助文案、等待 / 已完成标题为 regular。当前项默认标题不是功能色；悬停才切功能色 / 报错色。
- [ ] 标题与辅助文案间距为 4px，步骤间距不挤压文字。
- [ ] 末项贴步骤条右缘；首项序号左缘到末项标题右缘相对父级左右对称（或相对定宽容器左右对称）。
- [ ] 点击可用步骤后当前步骤和连接线同步更新；禁用项无响应。
- [ ] 键盘可聚焦并触发可用步骤，禁用项不可聚焦。
- [ ] 1280px、1440px、1920px 宽度下不溢出；长标题按产品场景另行确认截断策略。
- [ ] 换肤只改变功能色，文字、边框和禁用语义不被误换肤。
