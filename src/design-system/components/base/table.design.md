# 表格 Table · 设计规范（给设计师）

> 基础组件层。表格只管理「表格信息区 + 表体 + 表格自身状态」，不包含页面标题、筛选区、分页器、右侧锚点或业务提交按钮。

## 组件定位
- **表格 Table**：承载结构化数据的基础展示组件。
- **表格信息区**：表格内部的 40px 信息栏，和表体一起归入基础表格。
- **不在本组件内**：筛选区、分页器、录入型表格、树表格、嵌套表格、交叉表格、业务样板间。

## 结构
| 区块 | 是否属于基础表格 | 说明 |
|---|---|---|
| 表格信息区 | 是 | 默认计数、筛选计数、当页选中与批量操作 |
| 表头 | 是 | 列标题、排序、选择列、固定列 |
| 表体 | 是 | 文本、数字、状态、操作等单元格 |
| 空状态 / 加载 | 是 | 表格自身的数据状态 |
| 单元格加载 / 失败刷新 | 是 | 单元格自身的异步数据状态 |
| 分页器 | 否 | 独立基础组件，由复合表格组合 |
| 筛选区 | 否 | 属于「筛选表格」复合组件 |
| 录入型表格 | 否 | 属于「录入型表格」复合组件 |
| 树表格 | 否 | 属于「树表格」复合组件 |
| 嵌套表格 | 否 | 属于后续复合表格 |
| 交叉表格 | 否 | 属于复合表格；合并单元格与组悬停另读复合表格规则 |

## 表格信息区
| 场景 | 文案 |
|---|---|
| 默认 | 共 n 条 |
| 筛选后 | 已找到 n 条 |
| 批量选择 | 共 n 条，当页选中 n 条 |
| 筛选 + 批量选择 | 已找到 n 条，当页选中 n 条 |

- 高度固定 40px。
- 批量操作放在信息区右侧，不单独漂浮。
- 批量选择口径是「当页选中」，不是全量选中。
- 批量操作使用按钮，不使用链接。常规批量动作使用小号二级按钮；删除等其他风险使用小号二级弱警告（默认与二级同色，悬停 / 点击才变警告红）；弱操作如「取消选择」使用小号三级按钮。
- 信息区最右侧可放一个独立操作入口，例如刷新或列设置 icon；刷新使用 `reload`，设置使用 `setting`。
- 数据刷新入口与设置入口同属信息区右侧能力；真实数据请求和列配置面板进入复合表格。

## 表头内容组合
- 表头固定高度与表体定高规格一致，内容距左右边线均为 16px，并在高度内垂直居中。
- 标题使用 14px / 22px 中等字重；可选单位使用辅助文字 12px / 18px。
- 组合顺序固定为：**标题（可带单位）→ 帮助 icon → 排序 icon**；相邻元素间距均为 4px。
- 文本型列的组合靠左；数字、计数、金额、日期等可比较字段的组合整体靠右，避免数值比较时视觉跳动。
- 数值列以**标题文字右缘**作为表头 / 表体共用的右对齐锚点。单位、帮助 icon、排序 icon 仅跟随在标题之后，不把数值推到整组表头的最右侧；有排序时，数值单元格为 16px 图标热区和 4px 间距预留右侧空间。
- 帮助 icon 为 16px，悬停展示字段说明；排序使用 SensD `up-mini` + `down-mini`（各 8px），并保留 16px 点击热区。图标颜色使用可换肤图标 token。
- 简单排序严格按「默认 → 升序 → 降序 → 默认」循环：只有紧跟标题的 Sens 上下排序箭头可悬停与点击，标题及表头其余区域不触发排序；表头标题永不折行。视觉由 Sens 的排序图标与 `sens-table-sortable-*` 语义类承载，antd 只提供排序状态机。默认双箭头均为 `icon-color-transparent`；仅悬停的箭头为 `component-primary`，按下和当前方向为 `component-active`。无排序或仅悬停箭头时不加表头 / 列背景；升序、降序生效后，当前列表头与同列单元格均使用 `background-grey-hover` 承载。
- 「重要指标」等业务标记位于标题之后、帮助 icon 之前，复用正式 Tag，不手写色块。
- 个别样张因前置独立选择列产生的额外左侧空隙，属于表格列结构，不作为表头通用 padding。

### 列宽策略：定宽与自适应

- 设计稿逐列标注「定宽」或「自适应」；定宽列在实现中显式声明 `width`，自适应列不声明固定 `width`，承接容器剩余空间。
- 选择列、状态、时间、数字、操作等宽度稳定字段优先定宽；名称、描述等主信息优先自适应。两种列宽策略可在同一张表格中混用。
- 当定宽列与必要内容宽度超过容器可用宽度时，使用表格内部横向滚动；不可用任意定宽替代自适应列。
- 此规则属于基础表格；复合表格按业务列声明并消费，不另行复制实现。

## 列与单元格
| 类型 | 对齐 | 说明 |
|---|---|---|
| 文本 | 左对齐 | 超长内容截断并提供 hover 查看 |
| 数字 / 计数 | 右对齐 | 用于数量、比例、金额等可比较信息 |
| 状态 | 左对齐 | 状态点 + 文案，颜色按语义 |
| 操作 | 左对齐 | 常规蓝色链接按钮，固定为最后一列 |

- 单元格内容区以单元格边线的内侧范围为准；padding 从边线量到内容区，不从文字或控件外盒反推。
- **定高表格**：表头固定高；常规展示型表体同样使用固定高，左右 padding 16px、上下 padding 5px。单元格内可组合主文案和一行辅助信息，但不能因为内容增高而悄然改为自适应行。
- **录入型表格**：用于 Input、Select 等控件承载，左右 padding 8px、上下 padding 12px；录入型表格属于复合表格，但沿用这一单元格承载规则。
- **Padding 表格**：用于三行及以上文本、图文和复杂信息，左右 padding 16px、上下 padding 12px；内容从顶部排布，行高由内容撑开，不裁切、不以横向滚动代替纵向扩展。文本列保持左对齐，数值列保持按标题文字右缘的右对齐锚点。
- 同一张定高表格允许按单元格内容选择对应承载方式，但必须在列 / 行规格中明确；不得在未声明的情况下混用固定高与自适应高。

| 承载方式 | 典型内容 | 设计边界 |
|---|---|---|
| 定高表格 | 主文案 + 辅助文案、状态点 + 文案 + 链接、数值 + 同比、状态标签 + 文案 + 时间、开关、进度条、选择框 | 统一 56px 行高；主文案 14px / 22px，辅助信息 12px / 18px，信息组合在固定高度内垂直居中。 |
| 录入型表格 | Input、Select、带计数输入框、带图标 / 标签的选择器 | 单元格为控件保留左右 8px、上下 12px 的承载区；控件自身继续使用正式 Input / Select 规则。 |
| Padding 表格 | 三行及以上文本、缩略图 + 名称 + ID、置信区间 / 趋势图等复杂信息 | 内容从左上 16px / 12px 起排；图片、标签、图形与文字按所属组件规则组合，内容可把行高撑开。 |

### 待收录能力

- **缩略图表格**：属于基础 Table 的 Padding 单元格内容模式，待补独立可见样张（Figma `800:58263`）；不另定义业务组合。
- **横向 / 纵向拖拽**：属于基础 Table 的进阶交互，待补（Figma `774:43065`）；实施前需先定义拖拽对象、反馈、落点、取消和键盘可访问性。
- **树表格及局部加载**：属于复合表格；依赖树数据模型、父子选择、展开收起与节点级加载 / 失败刷新规则（Figma `724:29088`、`2649:75062`）。
- **嵌套表格**：属于复合表格；待定义父表 / 子表展开关系、缩进、边框与信息继承（Figma `724:29087`）。

### 单元格加载与失败刷新

- 单元格可单独进入加载或失败状态，不影响整张表的加载、空状态和信息区。
- 加载状态：仅展示旋转 loading icon，不展示「加载中」文字。loading icon 使用 `icon-color-transparent`；无障碍名称仍为「加载中」。
- 失败状态：`error` icon +「加载失败」+「刷新」链接；失败 icon 与文案使用 `warning-color`，刷新使用正式 14px 链接按钮。
- 刷新闭环由业务控制：失败 → 点击刷新 → 加载 → 内容（或再次失败）。

- 简单排序固定为三态循环：默认、升序、降序、默认；hover 显示排序提示。
- 多于三种排序方式时使用复杂排序菜单，必须保留当前排序信息；该能力待业务字段规则稳定后进入复合组件。
- 可下钻主属性默认中性文字，hover / active 进入链接蓝；操作列默认即为蓝色链接按钮。
- 文本过长使用 `TableEllipsis` 省略并在 hover 通过 Tooltip 展示完整内容；行内编辑、用户下钻、状态和 Tag 作为单元格组合使用，不新增表格专属业务组件。
- `StatusBadge` 目前作为旧组件出现在表格示例里，后续需要纳入全组件 SensD token 审计；表格文档只定义状态单元格可复用 Tag / 状态分类。

## 操作列
- 操作 1-3 个时平铺展示。
- 操作超过 3 个时，第 3 个起收进「更多」。
- 「更多」使用按钮体系里的下拉按钮，不手写普通链接或普通 Dropdown 文案。
- 操作文案以动词为主，如「查看 / 编辑 / 删除」。
- 表格超宽时，操作列固定在右侧。

## 选择态
- 复选框本体复用 `SensCheckbox`：未选 / 已选 / 半选（功能色底 + 白色横线）。不要用 antd 默认框内小方块。
- 复选框单元格分两种承载：树表格、录入型表格等需要解释选择对象的场景，使用「复选框 + 文案」，控件与文案间距 8px；批量操作使用无文案的**独立选择列**，列宽 32px，16px 复选框从列左侧 16px 起排、右侧贴列边。
- 行被选中后，行背景保持白色，不使用绿色选中底。

## 滚动与固定
- 产品壳与页面内容以 `1280px` 为最小桌面画布；视口窄于该宽度时，先由页面横向滚动展示完整画布，不压缩表格列或筛选结构。
- 在 `1280px` 产品画布内，表格必要列宽仍超过所在内容区时，才使用表格内部横向滚动。表格内部横向滚动不能替代页面级横向滚动；两层滚动可以同时存在。
- 需要横向滚动的管理类表格，建议固定首列或主属性列，并固定右侧操作列。
- 表头吸顶属于表格能力，但是否启用取决于具体页面高度。

## 空状态与加载
- 数据为空、筛选无结果、加载失败必须使用 SensD 非页面级空态：插画 + 标题 + 说明（添加 / 刷新为内嵌链接）。
- 空态区高度对齐 Figma `799:77513` / `77666` / `77819` 插画区 316，垂直居中。
- 三态空态不是数据行：悬停不加行 hover 灰底（`background-grey-hover` 只给有数据的行）。
- 加载态使用表格自身 loading，不替换为页面级加载。
- Figma 精确加载 GIF 尚未入库，当前先使用组件 loading 状态。
