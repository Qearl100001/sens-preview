## 定位

`SensUpload` 是单一基础组件，提供文件列表与图片缩略格两种呈现。点击选择是基础交互；`dragEnabled` 开启后支持拖拽投放。上传传输、模板下载与文件内容校验不属于组件职责。

## 使用场景与限制

- **文件样式**：适用于需要呈现文件名、大小和上传状态的附件或导入文件；可按场景开启单个或多个文件选择及拖拽。
- **图片样式**：适用于需要通过缩略图辨认、预览的图片上传；多图按选择顺序展示，上传入口置于末尾。
- **只读与禁用**：只读用于展示已上传内容且不允许修改；禁用用于入口仍需可见、但暂时不可操作的情况。
- **数量上限**：由业务按场景设置并通过 `maxCount` 传入；组件不规定统一数量上限。组件负责达到传入上限后的禁用入口与原因提示。预览轮播一页最多显示四张图，这只是查看层布局，不等于上传数量上限。
- **其他限制**：允许格式、文件大小上限和业务校验由调用方配置与处理；组件负责选择、拖拽接收和状态呈现，不负责文件内容校验或实际网络传输。

## 结构与状态

- 文件呈现：固定宽度 432px，窄容器内不溢出；列表、入口和拖拽投放区同宽。图片模式的 80×80 方形入口及图片格不受 432px 限宽影响。条目为白底、12px 内距、4px 圆角和 1px 浅描边。普通文件完成态一行展示附件、名称、大小和删除；完成态图片文件有本地或远端 `url` 时，左侧展示 58×58 缩略图，上传中/失败仍展示附件图标。
- 文件上传中：名称行下方缩进 20px 显示“上传中”、已上传大小 / 文件总大小、取消操作；悬停/聚焦“取消”时在上方显示 `SensTips`“取消上传文件”；下方显示 2px 轨道和功能色进度。
- 文件失败：外框及 2px 进度使用警告色；错误信息与操作位于名称行下方。支持“续传”或“重试”两种调用方指定的操作；大小/格式校验失败可仅显示删除。
- 文件只读：使用浅灰底、无描边；可显示大小和调用方提供的下载操作，不显示修改操作。只读图片完成态保留 58×58 缩略图。
- 文件样式只保留顶部“上传文件”入口；不显示重复的底部“继续上传”链接或文件数量角标。业务传入 `maxCount` 且达到该值时，顶部按钮和可见拖拽入口保留并呈禁用态，悬停显示“最多可上传 N 个文件”；未传 `maxCount` 时多文件模式没有组件统一上限。单文件模式仍最多接收 1 个；仅由 `disabled` 属性禁用时不显示数量原因提示。
- 文件和图片样式启用 `dragEnabled` 时都使用顶部 432×104 大投放区；文件列表或 80×80 图片缩略行显示在其下方。可编辑状态保留投放区，即使已有文件；只读状态隐藏投放区。图片拖拽模式不显示额外的小上传格，普通非拖拽图片模式仍按原规则把上传格追加在图片后面。
- 单文件拖拽模式由 `mode="file"`、`dragEnabled`、`multiple={false}` 组合启用，默认投放区最大宽度 432px、高 104px。依次覆盖默认、悬停、点击/拖拽中、禁用、禁用悬停、上传中、完成、完成悬停、只读、只读悬停、上传失败续传、上传失败重试、必填错误、必填错误悬停、必填错误点击/拖拽中十五态。已选择或拖入单个文件后隐藏投放区，删除后恢复；上传完成的图片作为 432×104 内容面板展示，悬停遮罩提供预览/删除，纯只读只提供预览。上传中显示进度与取消，失败显示进度及续传/重试操作；具体传输状态由调用方驱动。
- 图片呈现：80×80 缩略格、上传入口、悬停操作层；图片已上传项覆盖完成、只读、上传失败/续传、上传失败/重试、图片过大和格式错误。完成/只读展示图片缩略图；错误项用警告色虚线框，续传失败为环形进度图标，其余失败为警告错误图标。多个图片按 `files` 顺序排列，上传入口追加在最后（Figma `16830:58360`、`16830:58363`）；悬停层使用 `mask-01-transparent`；完成态显示预览/删除，只读态仅预览，带续传/重试标签的失败态显示对应操作/删除，图片过大与格式错误仅显示删除。键盘聚焦操作时显示同一操作层。
- 图片操作图标：预览、续传/重试默认白色，悬停切换为链接蓝 `link-color`、按下切换为 `link-active-color`；删除默认白色，悬停/按下分别切换为 `warning-color-hover` / `warning-color-active`。
- 图片预览：调用方响应 `onPreview` 展示查看层。Preview Demo 按 Figma `7869:1630` / `7869:3289` 展示大图、关闭操作、当前张数、单页最多四张缩略图、选中描边/未选中遮罩，以及上一组/下一组操作；仅一张图时不显示左右箭头。预览大图宽度随视口变化，左右各留 60px；高度按原图比例缩放，图片与上传时间信息间距为 `spacing/1x`（8px）。缩略图及左右切换控件距视口底部 60px，计数显示在轮播下方并保持 `spacing/1x`（8px）间距；大图与轮播之间的留白由可用高度动态分配，短视口下优先等比缩小大图。时间等附加信息来自业务，不由基础组件编造。
- 图片上传入口：默认底色使用 `background-transparent-grey`、虚线描边使用 `divideline-color-transparent-dack`；悬停描边切到功能色，按下描边切到功能点击色并显示 2px 点击投影环。禁用入口仍可见但不可操作；禁用悬停使用 `background-04-transparent`、`line-color-transparent` 和禁用悬停文字 Token。必填错误显示“请上传”，描边按默认/悬停/按下映射 `warning-color` / `warning-color-hover` / `warning-color-active`，按下使用警告点击投影。上传中入口项显示加载环与小尺寸弱化链接“取消”；悬停/聚焦时通过 `SensTips` 提示“取消上传文件”，实际取消由调用方 `onCancel` 处理。
- 拖拽态仅在启用 `dragEnabled` 后响应；进入区域时突出区域边界，释放后按 `multiple` 与 `maxCount` 规则接收文件。
- `readOnly` 显示现有文件但不提供修改操作；`disabled` 同时禁用入口和条目操作。
- 超长文件名中间省略，尽量保留文件名前段和末段及完整扩展名；悬停可查看完整名称。达到 `maxCount` 后，文件样式的顶部入口保留但禁用并提示上限原因；图片普通模式不显示新增入口，拖拽入口若仍可见则提示上限原因。
- 单文件上传完成后的重新上传文案、多文件入口文案由调用场景决定；本组件以列表管理为主。

## Token 映射

| 用途 | Token |
|---|---|
| 正文 / 辅助文案 | `text-color-transparent` / `text-sub-color-transparent` |
| 默认描边 / 图片描边 | `divideline-color-transparent-light` |
| 主操作 / 链接 | `component-primary` / `link-color` |
| 错误与错误底色 | `warning-color` / `warning-light-background` |
| 图片入口默认 / 悬停 / 按下 | `background-transparent-grey`、`divideline-color-transparent-dack`、`component-primary`、`component-active`、`component-active-shadow` |
| 单文件拖拽入口默认 / 悬停 / 按下 | `background-transparent-grey`、`divideline-color-transparent-dack`、`component-primary`、`component-active`、`component-active-shadow` |
| 图片入口禁用 / 禁用悬停 | `background-04-transparent`、`line-color-transparent`、`text-color-transparent-disable`、`text-color-transparent-disable-hover` |
| 图片入口必填错误 | `warning-color`、`warning-color-hover`、`warning-color-active`、`warning-color-active-shadow` |
| 图片已上传项错误 | `background-transparent-grey`、`warning-color`、`font-size/s`、`line-height/s` |
| 图片悬停遮罩 | `mask-01-transparent` |
| 图片预览查看层遮罩 / 文案 | `mask-01-transparent` / `white` |
| 图片预览当前态 | `component-primary` / `component-active-background` |
| 图片操作图标 hover / active | `link-color` / `link-active-color`；删除使用 `warning-color-hover` / `warning-color-active` |
| 进度轨道 / 只读背景 | `divideline-color-transparent-light` / `background-transparent-grey-hover` |
| 间距 | `spacing/1x`、`spacing/2x`、`spacing/3x`、`spacing/4x` |
| 圆角 | `radius/m` |
| 字体 | `font-size/m`、`font-size/s`、`line-height/m`、`line-height/s` |

设计定值：文件列表图片缩略图 58×58；图片缩略格 80×80；图片失败图标 20×20；拖拽区尺寸随容器宽度自适应。

## 验收

- 文件、图片两种真实 Demo；选择文件、拖入文件、删除、重试和预览回调可操作；从文件列表上传入口选择图片后显示对应缩略图。
- 默认、悬停、拖拽中、上传中、成功、续传失败、重试失败、大小/格式错误、只读、禁用、必填报错状态有状态矩阵。
- 图片入口的默认/悬停/按下、禁用/禁用悬停、加载取消、必填错误/悬停/按下九态均由真实组件交互呈现；加载取消调用 `onCancel`。
- 图片已上传项的六态及悬停操作使用 Figma 对照图：完成/只读使用缩略图；完成预览/删除、只读仅预览、续传/重试失败对应操作/删除、图片过大与格式错误仅删除。
- `onPreview` 接入后可打开 Figma 图片查看层；缩略图选择、最多四张可见、上一组/下一组、当前序号、关闭和 Escape 均可操作；四张仅为每屏展示数量，不限制上传张数。
- `maxCount` 由业务传入不同值时达到上限效果正确；不传时多文件模式不出现固定的业务数量限制；单文件模式仍只允许一个文件。
- 重试从 0 开始，续传从现有进度继续；此项只验证 Preview 回调模拟。生产传输仍由调用方更新状态。
- 单文件拖拽上传十五态由 `/components/upload` 矩阵呈现；顶部真实 Demo 支持文件选择和拖入，并通过状态回调展示完成/移除路径。
- 多文件拖拽上传六态（文件/图片 × 默认/完成/只读）由 `/components/upload` 矩阵呈现；真实 Demo 可切换文件与图片样式并分别选择或拖入多项。
- 使用语义 token；不新增 antd 样式覆盖、硬编码颜色或 `!important`。
- 在 1280–1920 宽度检查容器自适应、文件名省略和图片格换行。

## 边界与缺口

- 本组件负责浏览器文件选择、拖拽接收和呈现状态，不负责服务端传输、文件安全扫描、模板下载、批量内容校验及业务字段联动。
- 传输进度、失败状态和重试/预览行为由调用方通过文件状态与回调接入。
- 兼容格式、单文件大小上限、总容量和业务级错误文案由调用方配置。
