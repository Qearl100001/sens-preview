# 文件上传 Upload · 设计规则

> 来源：Sens.Design v2.1「上传」Figma（节点 `2315:29953`、`2316:33089`、`2315:29877`、`2315:29847`、`2315:29793`、`2315:29733`、`2315:29645`、`2315:29567`）；设计系统画布 `2216:10659`。文件列表细化状态参考设计系统 Figma 节点 `16835:58385`、`16835:58390`、`16843:59738`、`16835:58393`、`16835:58388`、`16835:58389`、`16835:58392`。

## 定位

`SensUpload` 是单一基础组件，提供文件列表与图片缩略格两种呈现。点击选择是基础交互；`dragEnabled` 开启后支持拖拽投放。上传传输、模板下载与文件内容校验不属于组件职责。

## 结构与状态

- 文件呈现：432px 设计最大宽度，窄容器内自适应；条目为白底、12px 内距、4px 圆角和 1px 浅描边。完成态一行展示附件、名称、大小和删除。
- 文件上传中：名称行下方缩进 20px 显示“上传中”、已上传大小 / 文件总大小、取消操作；下方显示 2px 轨道和功能色进度。
- 文件失败：外框及 2px 进度使用警告色；错误信息与操作位于名称行下方。支持“续传”或“重试”两种调用方指定的操作；大小/格式校验失败可仅显示删除。
- 文件只读：使用浅灰底、无描边；可显示大小和调用方提供的下载操作，不显示修改操作。
- 图片呈现：80×80 缩略格、上传入口、悬停预览/删除；上传中、成功、失败、只读和禁用状态。
- 拖拽态仅在启用 `dragEnabled` 后响应；进入区域时突出区域边界，释放后按 `multiple` 与 `maxCount` 规则接收文件。
- `readOnly` 显示现有文件但不提供修改操作；`disabled` 同时禁用入口和条目操作。
- 超长文件名单行省略，悬停可查看完整名称；列表容量到达上限后不再显示新增入口。
- 单文件上传完成后的重新上传文案、多文件入口文案由调用场景决定；本组件以列表管理为主。

## Token 映射

| 用途 | Token |
|---|---|
| 正文 / 辅助文案 | `text-color-transparent` / `text-sub-color-transparent` |
| 默认描边 / 图片描边 | `divideline-color-transparent-light` |
| 主操作 / 链接 | `component-primary` / `link-color` |
| 错误与错误底色 | `warning-color` / `warning-light-background` |
| 进度轨道 / 只读背景 | `divideline-color-transparent-light` / `background-transparent-grey-hover` |
| 间距 | `spacing/1x`、`spacing/2x`、`spacing/3x`、`spacing/4x` |
| 圆角 | `radius/m` |
| 字体 | `font-size/m`、`font-size/s`、`line-height/m`、`line-height/s` |

设计定值：图片缩略格 80×80；拖拽区尺寸随容器宽度自适应。

## 验收

- 文件、图片两种真实 Demo；选择文件、拖入文件、删除、重试和预览回调可操作。
- 默认、悬停、拖拽中、上传中、成功、续传失败、重试失败、大小/格式错误、只读、禁用、必填报错状态有状态矩阵。
- 使用语义 token；不新增 antd 样式覆盖、硬编码颜色或 `!important`。
- 在 1280–1920 宽度检查容器自适应、文件名省略和图片格换行。

## 边界与缺口

- 本组件负责浏览器文件选择、拖拽接收和呈现状态，不负责服务端传输、文件安全扫描、模板下载、批量内容校验及业务字段联动。
- 传输进度、失败状态和重试/预览行为由调用方通过文件状态与回调接入。
- 兼容格式、单文件大小上限、总容量和业务级错误文案由调用方配置。
