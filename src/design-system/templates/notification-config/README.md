# 样板间：交易日历通知配置

> 成熟度：Pilot<br>
> 实现：Implemented<br>
> 验证：Verified（当前范围浏览器交互验收通过）<br>
> 预览：`/templates/notification-config`

## 场景

以交易日历缺失提醒和交易日状态变更提醒为业务示例，演示如何将通用通知配置复合组件放入完整的抽屉配置流程。

## 页面组成

- `SensDrawer` 与 `SensTitleBar` 承接抽屉、返回、放弃和保存。
- `SensNotificationSettings` 承接可复用通知渠道与接收对象配置。
- 事件标题、说明、默认渠道和演示数据由样板间传入。
- 对象选择数据、邮件发件箱和 Webhook 实际服务尚未连接；保存仅提供本地演示反馈。

## 当前边界

- 截图提供了主页面结构与选择器外观参考；对象选择器尚无独立 Figma 设计稿，当前是按截图对齐的可交互还原。
- 邮件地址管理、Webhook 配置子流程、权限与服务端检索不在本次实现范围。
- 抽屉默认打开、放弃关闭、重新打开与保存后的演示反馈已通过浏览器验收；真实持久化仍由调用方负责。
