# SDH 录入型表格样板间

> 预览入口：`/templates/sdh-editable-table/event-scroll`  
> 依赖复合组件：`/composite/table` · 录入型表格

## 样板间定位

SDH 录入型表格样板间用于承接真实业务页面中的结构化录入场景。它不是新的表格组件规范，而是展示业务对象、页面结构和提交流程如何消费「录入型表格」复合组件。

## 首轮收录场景

| 场景 | 说明 | 当前状态 |
| --- | --- | --- |
| 新增元事件 / 滚动 | `/templates/sdh-editable-table/event-scroll`；用于新增元事件时配置属性字段。 | 页面样板首轮 |
| 物料元素录入 | `/templates/sdh-editable-table/material-element`；用于连续新增物料元素。 | 页面样板首轮 |
| 创建维度（事件属性） | `/templates/sdh-editable-table/create-dimension-event-property`；用于从事件属性创建维度。 | 页面样板首轮 |

## 使用规则

1. 业务样板间只消费复合组件规则，不重新定义基础输入框、选择器、按钮、表格行高和 token。
2. 表格主体继承录入型表格规则：行高 56px，组件型单元格左右 padding 8px，上下 padding 12px，纯文字 / 链接文字单元格左右 padding 16px。
3. 非组件文本单元格最多展示 2 行，不因长文案撑高行。
4. 最后一行新增入口使用小号链接按钮 + `editor-add` icon；每次点击都在新增入口前增加一行空白可编辑数据，入口始终位于最后一行。
5. 表格字段报错直接复用基础 `SensInput` 与 `SensSelectDropdown` 的框内报错状态：红色边框 + 右侧错误菱形图标，悬停图标显示字段错误说明。
6. 每个场景都是独立页面，复用已录入的顶部导航和 `SensPageTitleBar`；样板间目录放在预览系统左侧导航的 `SDH / 录入型表格` 分组中，不放入业务正文。
7. 样板间标题、说明、右侧锚点和提交动作属于业务页面结构，不回写到复合表格组件。
8. 创建维度（事件属性）的「值预览」是业务列：可展示 `Loading / Missing`、加载失败 + 刷新、以及空结果；其中 Loading GIF 尚未录入 SensD，继续标记 Missing。点击「添加维度」会在入口前插入一行空白可编辑维度，新增入口始终保持最后一行。

## 当前不做

- 不做删除行、保存提交、离开保护。
- 不做完整字段校验矩阵与行级错误汇总；当前仅以字段级报错示例说明基础控件的消费方式。
- 不做右侧锚点真实滚动联动；当前只保留 `Anchor / Missing` 插槽，待锚点组件补齐后替换。
- 不做滚动条组件样式。
- 不补 104px 特殊选择器宽度；继续遵守已确认的 Select 宽度规则。
- 不录入数据类型图标；当前以文字展示类型名称和英文类型，避免用错误图标替代。
