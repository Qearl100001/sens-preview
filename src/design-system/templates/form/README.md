# 表单样板间（已迁移）

> 当前归属：已迁移到「复合组件 / 复合表单」。正式预览入口为 `/composite/form`，不再维护旧的 `/templates/form` 路由。

## 迁移原因

带表格表单、联动表单和卡片表单不绑定具体业务对象，沉淀的是可跨业务复用的表单组合模式，因此归入复合组件，而不是业务样板间。

## 当前复合表单

| 样板间 | 适用场景 | 关键规则 | 依赖 |
| --- | --- | --- | --- |
| [带表格表单](./table-form.md) | 需要在一张表单中录入或配置结构化多行数据 | 表格永远位于所属标题下方，不受表单上下 / 左右布局影响 | Form、Title、Table、Button |
| [联动表单](./linked-form.md) | 单选或复选的选择结果决定后续字段、卡片或提示是否出现 | 四类联动结构均覆盖上下、左右布局；带辅助文案或关联内容时，标题与内容顶对齐，二者均不补 `32px` 外框 | Form、Radio、Checkbox、Input、Select |
| [卡片表单](./card-form.md) | 信息层级较深，需要使用白描边卡与灰底卡建立分组 | 覆盖灰条分组、左右布局卡、关联灰底卡；灰条下内容以 `16px` 与标题文字对齐 | Form、Title、Card Foundation |

正式规则见 `src/design-system/components/composite/form.md`。
