# 带表格表单

> 来源：Figma `Sens.Design 表单组件 v2.1 221206` · `64:39725`。
> 状态：P1 已录入。

## 适用场景

当普通字段之外还需要录入、选择或维护结构化多行数据时使用，例如属性配置、范围配置、成员清单和规则明细。

## 结构

1. 表单标题或分组标题。
2. 普通字段，可使用上下或左右表单布局。
3. 表格标题。
4. 表格信息区、表头与表体。
5. 页面操作区。

## 核心规则

- 表格是标题下的独立内容区，**永远采用上下关系**；不得随外层表单切换为左右布局。
- 灰底标题通栏拉满内容区；仅表格外框内缩 `spacing/horizontal/4x`（16px），与标题文案左边对齐，不得把灰底标题容器一起缩进。
- 灰底标题到表格的纵向间距固定为 `spacing/vertical/4x`（16px）。
- 表格上方的标题和说明由 Form / Title 规则管理；表格列、行、批量操作、空态和分页由 Table / Pagination 规则管理。
- 表格宽度跟随其所在内容区，不以 Form 单控件 `form/control/max-width` 限制表格。
- 表格内发生校验时，字段级报错保留在对应单元格或行的表格规则中；不要把行级报错移动到表单普通字段的辅助信息行。

## 不适用

- 仅展示数据、没有提交或配置语义时使用管理列表样板间，而不是带表格表单。
- 表格本身就是整页主体时，不要套用表单的字段节奏。
