# 卡片表单

> 来源：Figma `Sens.Design 表单组件 v2.1 221206` · `62:16455`。
> 状态：P1 已录入三种卡片结构。

## 适用场景

表单的信息层级超过标题和普通字段能承载的范围，需要强调一组独立的配置上下文、可选结果或关联规则时使用。

## 三种结构

| 样式 | 结构 | 使用场景 |
| --- | --- | --- |
| 样式一 | 灰条大标题 + 同组内容 | 页面顶层分组，标题、说明和字段属于同一组信息 |
| 样式二 | 左标题 + 右侧独立描边卡 | 左右布局中，复杂控件区需要独立边界 |
| 样式三 | 常规字段 + 关联灰底卡 | 选择结果触发局部配置，关联字段需要收紧呈现 |

## 通用规则

- 灰色大标题下的同组内容，纵向间距固定 `spacing/vertical/4x`（16px）；左右内缩使用 `spacing/horizontal/4x`（16px），内容左边必须与标题文字左边对齐，不与灰色背景容器外边缘对齐。
- 卡片通栏展示，圆角使用 `radius/l`（6px）。
- 卡片内标题不得超过三级标题；灰底卡内只使用 `font-size/m`（14px）标题。
- 同一个业务页面不同时使用超过两种卡片样式；样板间可独立展示三种样式以说明边界。
- 两层卡片嵌套只允许「白底描边卡 -> 灰底卡」；禁止灰底卡内继续嵌套白描边卡。
- 卡片用于建立信息边界时，优先于分割线；卡片不改变 Form 的标题、省略、辅助文案、校验和操作区规则。

## 分组层级

| 层级 | 容器与标题规则 |
| --- | --- |
| 页面 / 顶层 | `SensSectionTitle`，`16px` 标题和灰条 |
| 白描边卡 | 可重新开始一棵分组树；卡内可以再次使用顶层标题和灰条 |
| 灰底卡 | 承载紧密关联的字段；卡内标题只能使用 `14px`，不再嵌套白描边卡 |

## 依赖与边界

- 白描边卡、灰底卡的基础容器样式引用 Card Foundation；样板间只定义其在表单中的层级、对齐与使用条件。
- 当卡片由 Radio / Checkbox 触发时，联动规则优先于单行控件的 `32px` 高度规则。
