- [决策] 以一个 `SensUpload` 提供文件列表与图片缩略格两种呈现；拖拽是可选交互，业务传输、模板下载和内容校验留在场景层。
- [规则] 新增文件上传设计规则与研发说明，记录状态边界、调用方契约和 Token 映射。
- [实现] 新增 `SensUpload`、文件选择/拖拽/列表/缩略格交互、真实 Demo、状态矩阵与 Prototype Kit 公共出口。
- [token] 使用 `text-color-transparent`、`text-sub-color-transparent`、`divideline-color-transparent-light`、`component-primary`、`link-color`、`warning-color`、`warning-light-background`、间距、圆角和字体 Token。
- [验收] ✅已验「`npm run build`、Token 检查、TypeScript、生产构建、Prototype Kit 隔离打包」；✅已验「浏览器 1280 / 1920 宽度、文件/图片样式切换、删除、必填错误展示」；🔶待验「真实文件选择与拖入、图片预览/重试按钮、换肤」。未将构建通过当作完整浏览器验收。
