## Select · 展示型单行缩略 / 多行换行

- [决策] 推翻 08-13「触发框锁 32px 单行、取消 88 多行、超出裁切」。展示型默认仍单行 32：能放下的标签照常展示，长标签整颗 **112px** 截断，放不下末尾 **`…共 N 项`**（N=已选总数，不是 antd `+N` 剩余数）。`tagsWrap` 显式多行：换行，min 32 / max **128**，超出滚动，展示全部、不用 rest。Figma `15584:52705` / `15584:52788`。
- [决策] 确认打开时触发框 `value` 钉在已提交；草稿只驱动菜单复选与「完成 (N)」。不再用 `maxTagCount={0}` + 整段 committed placeholder（会和 responsive rest 打架）。
- [实现] `tagsWrap`；单行默认 `maxTagCount="responsive"` + `sens-select-tags-rest`；多行 class `sens-select-tags-wrap`；`SELECT_TAGS_MAX_HEIGHT=128`、`SELECT_TAG_CHIP_MAX_WIDTH=112`。Demo：排法「单行 | 多行」、多行宽 600、城市名极限数据。
- [坑] 单行 overflow-item 不要强制 `display:flex`，否则盖掉 antd responsive 的 `display:none`。SensTag 根节点内联 `max-width:100%` 会盖 CSS，须在 tagRender 传 `style.maxWidth=112`。
- [token] 标签间距 / 文案箭头 gap `spacing/horizontal/1x`；上下 `spacing/1x`；标签高 `size/component-height/s`；左右 `spacing/horizontal/3x`
- [验收] ✅已验「Playwright `/components/select`：单行 320×32，可见北京 + 长标 112 + `…共 40 项`；多行 600×128、wrap、scrollHeight>clientHeight、无 rest、长标 112；确认打开勾选广州后触发框仍 `…共 40 项`、完成变 `(39)`，点完成后 rest=`…共 39 项`」
