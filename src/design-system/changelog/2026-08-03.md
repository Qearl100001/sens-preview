## Tabs · 页签标签页缝合空隙修复

- [决策] 页签标签页与内容卡保持缝合 **0px**；空隙来自 antd 加号默认 `min-height:40px` 把 nav 撑到 40，页签仍 32 顶对齐，底边露出约 8px 白缝——压掉加号 min-height，并将 nav 底对齐，不改成基础标签页那种内容间距。
- [实现] `tabs.css`：`.ant-tabs-nav-add` / `.ant-tabs-nav-more` 同步 `min-height` 为 `--sens-card-tab-height`；nav / nav-list / operations `align-items: flex-end`。
- [token] `--sens-card-tab-height` ← `size/component-height/m`
- [坑] 只设 `height: 32px !important` 压不过 antd 的 `min-height: 40px`，used height 仍被抬到 40。
- [验收] ✅已验「Playwright：`gapInactiveToHolder=0`、`navH=tabH=addH=32`、`addMinH=32px`」

## Navigation Color · 标题栏 / 页面底接导航 token

- [决策] 标题栏与顶导下页面底本就有 handle（`theme-title-background` / `body-background`），问题是组件裸读 `getColorToken` 锁死绿基线；改走 Appearance CSS 变量 / NavigationTheme helper，保证换肤仍是 design token。
- [实现] `navigation-color.ts` 增 `getThemeTitleBackground` / `getThemePageBackground` / `navigationCssVar`；`SensPageTitleBar` / `SensTitleBar` / `SchemaManagementPage` 读 `--sens-nav-title-bg`；`TopNavigationShowcasePage` 顶导下衬底改 `getThemePageBackground`（`body-background`）。

- [坑] 顶导展示页曾误用标题栏 handle 充当页面底；两槽位当前同色，语义仍须分开。
- [验收] ✅已验「Playwright 切蓝：`--sens-nav-title-bg/#F5F7FA`；drilldown 标题栏 computed `rgb(245,247,250)`；顶导下衬底同色」
