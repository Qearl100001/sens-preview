# 设计还原产线 · 更新日志 · 10月14日

> 记录对视图切换组件交互规则与预览状态矩阵的收口。

## View Switch / 视图切换

- [实现] 移除状态矩阵每行延伸至空白区域的横向分割线，保留状态间距、状态标签和按钮自身描边。
- [交互] 移除 SensD 键盘操作说明与自定义焦点样式；保留原生按钮语义，不额外定义键盘规则。用 `aria-pressed` 表达当前选中视角。
- [验收] 用户确认绿 / 蓝换肤表现无问题；Token 检查、TypeScript 检查与生产构建通过。浏览器自动化连接不可用，交互及当前视觉改动未由本轮独立浏览器复验。

## Preview 演示控制

- [实现] 基础组件预览页中的单选演示控制统一改用 `SensViewSwitch`；保留各演示项原有选项、值和禁用条件。布尔开关、标签导航和选择器不在本次范围。

## Switch / 开关

- [实现] 新增独立 `SensSwitch`，区分于 `SensViewSwitch`；支持受控 / 非受控、即时切换、状态文案、禁用、加载和只读展示。
- [规则] 补充开关使用场景、限制与 Figma 状态定义；只读态必须显示当前“已开启 / 已关闭”信息。
- [预览] 新增 `/components/switch`，包含可交互 Demo 和状态矩阵；Figma 标注不支持的“只读且隐藏状态文案”以提示呈现。
- [验收] 等待浏览器视觉与交互验收，状态维持 `Pilot · Implemented · Pending`。
- [修正] 加载图标改为 12px，与滑块内空间一致并居中；关闭态加载图标使用中性图标色，开启态继续跟随功能色。

## Notification / 通知复合组件

- [决策] 将通知方式与成员 / 角色 / 职务对象选择沉淀为复合组件；完整交易日历配置页留在样板间，避免把业务整页定义成复合组件。
- [实现] 新增 `SensNotificationSettings` 与 `SensRecipientSelector`，复用 Sens Checkbox、Radio、Select、Button、Tabs、Popover、Alert、Drawer 与 TitleBar；对象选择采用草稿 / 确认，不接入虚构后端服务。
- [预览] 新增 `/composite/notification` 与 `/templates/notification-config`；无独立设计稿的对象选择浮层按用户截图尽量还原。
- [文档] 新增对象选择器、通知配置与交易日历通知样板规则，并登记到设计系统入口。
- [验收] Token 检查、TypeScript 检查、生产构建与 `git diff --check` 通过；浏览器自动化连接不可用，视觉与鼠标交互待浏览器复验，当前为 `Pilot · Implemented · Pending`。
- [决策] 通知系统预览按复合表单分项，不使用基础组件展示壳。当前只保留一项「通知配置与对象选择」，对象选择留在该项内，不再与通知配置拆成两个顶部选项。
- [验收] ✅已验「浏览器 `/composite/notification`：顶部只有「通知配置与对象选择」，指定成员里打开对象选择浮层」。

## 对象选择器 / 分组标题与移除按钮

- [决策] 已选区分组名「成员 / 角色 / 职务」使用四级标题，不用三级标题。移除按钮悬停只改变图标颜色，不铺悬停底。
- [实现] 分组名改为 `font-size/m`、`line-height/m`、`font-weight/medium`。移除图标改为继承按钮颜色，悬停色为 `warning-color`，悬停背景保持透明。
- [token] `font-size/m`、`line-height/m`、`font-weight/medium`、`warning-color`、`text-sub-color-transparent`。
- [验收] ✅已验「浏览器计算样式：成员 / 角色 / 职务为 14px / 22px / 500；移除按钮默认透明底、弱化色，悬停无底且图标为 warning-color」。

## 基础组件预览 / 布尔开关换 SensSwitch

- [决策] 基础组件演示区的布尔开关改用 `SensSwitch`。多选项仍用 `SensViewSwitch`。不打开状态文案，避免和旁边已有标签重复。
- [实现] 按钮、标签、上传、警告、选择器、复选框、单选框、多行输入、徽标、分页、轻提示、输入框、数字输入、视图切换、标签页、搜索、抽屉的演示开关，以及表格定高单元格里的展示开关，都从 antd Switch 换成 `SensSwitch`。禁用与加载、禁用与只读的互斥保留。
- [验收] ✅已验「浏览器：按钮页 disabled / loading 互斥生效；上传页打开禁用后组件带 is-disabled；表格单元格开关为 32×20 且保持开启。这些页不再出现 antd Switch」。

## 气泡卡片 / 筛选改视图切换

- [决策] 气泡卡片演示的尺寸、方位、箭头是互斥筛选，改用 `SensViewSwitch`。打开气泡、超长示例和卡片内按钮仍是操作按钮。
- [实现] 普通气泡和二次确认各一组筛选。二次确认尺寸只有小、中，两组状态互不影响。
- [验收] ✅已验「浏览器 `/components/popover`：普通气泡可切到小、下，二次确认仍保持小、上，再切二次确认尺寸到中时普通气泡不变」。
