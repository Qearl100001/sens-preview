# Layout Foundation

> 定义页面骨架、断点和左侧区域行为；不定义栅格列数或侧导航组件 API。<br>
> 成熟度：Pilot<br>
> 实现：Partial<br>
> 验证：Pending<br>
> 来源：Figma `Sens.Design 栅格布局 v0.3 220505`、`设计系统 2.1 侧导航设计`、`DESIGN.md`、`DataSourceManagementPage.tsx`、`SensPageTitleBar.tsx`。<br>
> 预览：`/basic-styles/layout`

## 1. 定位

Layout 负责页面区域之间的关系：顶部、左侧、标题区、主内容区如何组合，以及可展开左侧区域是否影响主内容宽度。

它不回答“卡片占几栏”或“每栏多宽”；这些属于 [Grid Foundation](./grid.md)。

## 2. 页面骨架

| 骨架 | 适用场景 | 结构 | 规则 |
|---|---|---|---|
| T 型布局 | 三级落地页、带产品壳导航的管理页 | 顶部导航 + 左侧产品壳导航 + 主内容区 | 产品壳侧导展开宽度固定为 `220px`；右侧标题栏贴合顶部，标题栏与首个工具区间距为 `0px`；内容模块左右 padding 为 `24px` |
| 上下布局 | 四级页面、独立管理页、下钻详情页 | 标题 / 操作区 + 下方内容区 | 标题区不承担复杂分栏；下钻页白色正文区 padding 为上下 `16px`、左右 `24px`，内容区再选单栏、双栏、列表或表单结构 |
| 上下布局 + 上下文侧栏 | 锚点、目录、详情辅助区 | 页面内左侧辅助区 + 主内容区 | 由页面决定是否展开；展开和收起后主内容重新计算可用宽度 |

`220px` 只表示当前产品壳侧导的展开结构尺寸，来源于侧导航 Figma 和当前产品壳实现；它不是通用页面左栏 token。

### 2.1 标题栏与正文的贴合关系

| 布局 | 标题栏位置 | 标题栏到正文 | 正文容器 |
|---|---|---|---|
| T 型布局右侧区域 | 标题栏从右侧区域顶部开始，顶部 padding 为 `0px` | 标题栏与首个工具区间距为 `0px`；工具区后的模块间距按模块规则处理，表格工具区到表格可为 `16px` | 内容模块左右 padding 为 `24px` |
| 下钻页上下布局 | 标题栏独立于白色正文区 | 标题栏后直接进入白色正文区，不额外增加布局 gap | 白色正文区使用上下 `16px`、左右 `24px` padding |

以上 `16px` 与 `24px` 分别消费 `spacing/vertical/4x`、`spacing/horizontal/6x`。`0px` 表示区域贴合关系，不新增 token。

## 3. 左侧区域的行为

左侧区域都可能展开或收起，但不能因此被当作同一个组件。

| 区域类型 | 行为 | 触发方式 | 主内容是否变化 | 颜色归属 |
|---|---|---|---|---|
| Product Shell Side Navigation | Overlay | 鼠标悬停临时展开 | 不变；侧导浮在内容之上 | Navigation Theme |
| Product Shell Side Navigation | Docked | 用户锁定展开 | 变化；内容区使用剩余宽度 | Navigation Theme |
| Context Side Panel | Reflow | 锚点 / 目录 / 辅助信息展开收起 | 变化；内容区和其中栅格重新计算 | Foundation 或组件自身语义 |

约束：

- 产品壳侧导的 `Overlay` 与 `Docked` 是导航组件状态，不应由页面各自模拟。
- 锚点、目录等 `Context Side Panel` 属于页面内容，不自动复用 `theme-side-*` 颜色。
- `Grid` 只消费 Layout 算出的可用内容宽度，不决定左侧区域的宽度或交互。

## 4. 断点与适配

| 断点 | 宽度 | 页面策略 |
|---|---:|---|
| XS | 1280 | 静态布局；结构保持稳定，必要时横向滚动 |
| SM | 1366 | 桌面端常规响应式验收区间 |
| MD | 1440 | 设计画布默认宽度 |
| LG | 1600 | 大桌面内容可更舒展 |
| XL | 1920 | 保留更宽的内容展开空间 |

- 小于 `1280px` 不强行折叠或换行产品壳结构，采用横向滚动保护信息层级。
- 大于等于 `1280px` 时，页面根据实际可用内容宽度自适应。
- 左侧区域在 `Docked` 或 `Reflow` 状态下变化后，主内容和其内部栅格都应重新计算，不保留旧宽度。

### 4.1 产品最小画布

`1280px` 是产品级电脑端最小画布约束，由 Layout / Product Shell 统一承载；基础组件、复合组件和业务样板间只消费该约束，不各自重新定义。

- 当视口宽度小于 `1280px` 时，产品壳和页面内容保持 `1280px` 最小宽度，通过横向滚动查看完整内容。
- 不因小于 `1280px` 自动进入移动端布局，不压缩顶部导航、侧边导航、表单、表格或筛选区的结构。
- 复合表格、复合表单等组件页面可以声明“在产品最小画布内验收”，但不应在组件内部硬编码产品画布宽度。
- 如果局部容器本身宽度小于组件所需宽度，应先判断是否是页面布局 / 栅格 / 容器约束问题，不能默认让组件自行换成另一套小屏形态。

## 5. 内容区滚动与产品壳收起

> 来源：`Sens.Design 表单组件 v2.1 221206` · 表单滚动 `62:17059`；该节点当前待补可读取的完整交互稿。这里先沉淀已确认的归属和边界，不推导未确认的阈值或动效数值。

### 5.1 定位

内容区滚动驱动的产品壳收起是跨页面 Layout 行为，可被长表单、表格、详情和配置页引用；它不是 Form、Table、锚点或某个业务页面专属的样板间。

| 行为层 | 负责内容 | 不负责内容 |
| --- | --- | --- |
| Layout / Product Shell | 滚动容器归属、产品顶导展开 / 收起、收起后可用高度变化 | 表单字段、表格列、锚点目录的业务内容 |
| 页面 / 样板间 | 声明是否启用该行为，组织主内容 | 自行复制顶导收起动画或写另一套产品壳高度 |
| Context Side Panel | 在当前产品壳高度下定位锚点 / 目录 | 继承 `theme-side-*` 或控制产品顶导 |
| Table / Form | 自身区域内的滚动与状态 | 反向定义页面产品壳行为 |

### 5.2 已确认行为

- 仅页面的**主内容滚动容器**可以驱动产品壳收起；一个页面只能有一个容器承担该职责。
- 产品顶导有 `expanded` 与 `collapsed` 两态。内容向上推进、达到阈值后进入收起态；回到顶部附近时恢复展开态。
- 收起后主内容获得额外**可用高度**，但不改变主内容宽度、页面骨架、栅格列数或卡片 / 表格 / 表单的横向布局。
- P0 只定义产品顶导收起；页面标题栏是否吸附、侧导是否联动、表格表头是否吸顶，必须在各自组件或后续规则中确认，不能默认一起收起。
- 锚点 / 目录将来需要吸附时，偏移量必须由当前产品壳实际高度派生，不能写死一组顶部距离。
- 组件内部滚动（例如表格 body、选择器下拉面板、文本域）不等于页面主内容滚动，不能触发产品壳收起。

### 5.3 主题与实现边界

- 收起前后的产品顶导继续消费 `Navigation Color / Product Shell Theme`；内容区、锚点、目录和表格不继承 `theme-top-*` 或 `theme-side-*`。
- 间距、标题栏高度、颜色、描边和阴影继续消费既有 SensD token / helper。
- 滚动阈值、滞回区间、动效时长和缓动目前属于 Layout 行为配置，状态为 `To Confirm`；未在多个页面稳定验证前，不升为全局 Design Token。
- 未明确启用该行为的页面默认保持产品壳展开，避免业务页自行猜测滚动策略。

### 5.4 验收

- 在长表单、表格或详情页中，页面能说明唯一的主内容滚动容器。
- 收起 / 恢复时不产生内容横向抖动、宽度重算或重复的顶部间距。
- Context Side Panel 的定位不硬编码产品壳高度，且不复用产品壳导航颜色。
- 未读取到完整 Figma 交互稿前，不声称已确认阈值、动效或标题栏联动规则。

## 6. 与其他 Foundation 的边界

- `Grid`：列数、占栏和局部容器排布。
- `Spacing`：区域和组件之间的 `padding`、`margin`、`gap` 数值。
- `Size`：固定尺寸档位；不负责整页区域关系。
- `Card`：卡片容器样式；不决定卡片在一行排几张。
- `TitleBar`：标题区内部结构；不决定整页骨架。

## 8. 代码落地规则

- 当前不新增独立 Layout token 生成链路。
- 产品壳侧导宽度、内容最大宽度、页面边距、双栏比例等，如需反复消费，优先判断为 `config / 常量`，不直接提升为全局 token。
- 页面选择骨架后，再由 Grid 组织内容；不要由 Card、Table、Form 反向定义整页结构。
- 页面需要滚动收起时，优先由产品壳 / Layout 提供状态和当前高度；页面组件只消费状态，不复制监听与收起逻辑。

## 9. 第一阶段验收

- 页面能明确选择 T 型、上下，或上下 + 上下文侧栏骨架。
- 需要展开 / 收起左侧区域时，能先判断 Overlay、Docked 或 Reflow。
- 低于 `1280px` 时页面不会因强行压缩而丢失结构。
- 长页面可先判断是否需要引用“内容区滚动与产品壳收起”，而不把滚动误归为表单私有能力。
