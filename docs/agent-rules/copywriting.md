## 一句话

页面上的用户可见文字按 Sens 官方书面语书写。视觉还原、token 替换或「任务被标成视觉」都不能跳过本文。

流程动词（创建 / 放弃 / 提交 / 创建成功等）只看 `consistency-flow-rules.md`。按钮两字空格、搜索占位、Input 默认「请输入」只看对应组件文档。冲突时：先本文，再组件例外。

## 何时必读

页面生成或修改完成后必须对照本文过 `page-evaluation-checklist.md` §4。

- 样板间、案例、产品页：必过。
- 组件 Demo 改了用户可见字符串：必过。
- 本轮只改 token / 间距 / 颜色、可见字符串未动：记「本轮无文案变更」。
- 纯组件 API / 状态矩阵、无页面文案：不过。

不要全仓库扫描；只验本轮改过的页面上用户可见字符串。顶导 / 侧导 IA 专名另开一轮，不和本轮页面文案混改。

## 一、原则

- 使用行业专有名词；如非必要勿增实体。
- 代表官方传达信息：正式、精炼、准确；不用口语、网络词汇和夸张语气助词。
- 同一功能、名词、单位保持统一；类似语境下语序和格式保持统一。
- 以帮助用户高效完成工作来组织内容和语言。高效率体现在：准确性、易阅读、易理解、无困扰。

## 二、书写规范

### 通则

- 精简，避免冗长。
- 不要用「您 / 你」做人称主语。
- 数量用阿拉伯数字。
- 中文或中英混排句使用中文全角标点；整句英文才用半角标点。
- 中文与非中文（拉丁字母、数字）之间加 1 个空格，中文标点两侧不加空格。例如：`请于 2023 年 12 月 31 日前完成续费`。
- 禁止感叹号 `！` / `!`。
- 段落不加首行缩进。
- 专业名词、名称、缩写用直角引号 `「」`，多项之间用顿号 `、`。

### 2.1 固定格式

| 类型 | 规则 | 示例 |
|---|---|---|
| 品牌 | 中文品牌用中文，外文品牌用官方大小写 | `支持 iOS 系统和 Android 系统` |
| 文件 | 格式名大写；扩展名 `.` + 小写 | `请上传 PNG/GIF/SVG 格式图片`；`数据表模版.txt` |
| 日期 | 嵌在句子里用中文年月日；独立数据用 `-` | `请于 2023 年 12 月 31 日前完成续费`；`更新于：2023-12-31` |
| 图片尺寸 | 数字与 `*`、`px` 之间不加空格 | `请上传 100*100px 的图片` |
| 范围 | 用 `~` 或 `至` | `2023-12-01 至 2023-12-31` |
| 数值运算 | 数字与 `+ - × ÷ =` 之间不加空格 | `(12+4)÷2=8` |
| 表达式 | 字段与运算符号之间不加空格 | 系统表达式连写 |
| 数据缩写 | 大于 1000 用千分位 `,`；缩写可用 `k` | `521,342`；`521k` |
| 比例 | 用半角 `:` | `缩略图比例 4:3` |

独立时间戳（如 `2020-06-01 00:00:00`）按「数据」日期，不改成中文年月日。

### 2.2 空格

**加空格：**

- 英文与中文之间（中文标点除外）
- 数字与中文之间（中文标点除外）
- 数字与单位之间（下列例外除外）

**不加空格：**

- 中文标点与两侧任何字符
- `100%`、`90°C`、`100px`
- 比例 `4:3`
- 尺寸 `100*100px`

### 2.3 标点

短标签、辅助说明、`description`、`labelHelp`、Tips、Alert 警告条、轻提示、校验和空态公式：**句末不加句号**。UI 文案尽量避免句号。Alert 即使是长句也不加句号（已收口）。

改变语义的问号、冒号必须保留；中文问号用全角 `？`。

| 符号 | 用法 | 示例 |
|---|---|---|
| `/` | 并列「或」 | `请输入 SLink 链接/SLink 名称/SLink ID` |
| `、` | 并列「和」 | `「元事件」、「虚拟事件」` |
| `，` | 长句停顿 | `表格中的名称排序，按创建时间倒序排序` |
| `；` | 并列完整分句 | `仅支持 PNG 格式的图片；建议使用白底图片` |
| `。` | 尽量不用 | — |
| `「」` | 专名 / 缩写 | `事件类型可分为「元事件」、「虚拟事件」` |
| `：` | 提示语停顿，或详情页「标签：内容」 | `画布名称：618 大促活动` |
| `:` | 仅表示比例 | `4:3` |
| `（）` | 完整句中的局部解释 | `避免将「人称代词」作为文案主语（如「您/你」）` |
| `()` | 非完整句中解释对象；对象与括号之间 1 个空格 | `已完成 (12)` |
| `~` | 数值或时间范围 | `22:00 ~ 23:00` |
| `-` | 复合名词或日期 | `2023-12-31`；`数据详情-数据表设置` |
| `,` | 大于 1000 的千分位 | `1,923,200 人` |
| `*` | 脱敏 | `手机号：133****2323` |

中文句里不要出现半角 `,` `.`。计数括号的半角 `()` 以 `button.md` 为准。

### 2.4 为空

| 类型 | 显示 | 何时 |
|---|---|---|
| 数据型 | `暂无数据` | 计算尚未开始、没有有效数据 |
| 数据型 | `0` | 计算正常，当前累计值为零 |
| 通用型 | `-` | 该项永远不会有数据 |
| 通用型 | `未设置` | 只读展示且尚未配置 |
| 兜底型 | `NA` / `NULL` | 缺测 / 位置不存在；用法须产品或研发确认，不要默认拿来填空 |

样板间不要用 `0,000` 这类假千分位冒充空态。会有数据但当前没有可展示值时，指标用 `-`；计数类占位（如 `n 条已上线`）不是空态，应写成具体数字，不要改成 `-`。

## 三、流程场景

对象流程的入口、底部按钮、成功反馈只引用 `consistency-flow-rules.md`，本文不重复「放弃 / 提交 / 创建成功」。

创建入口可用 `创建XX` 或 `新建XX`。不要用「确定」「取消」代替后果清晰的动词。

## 四、提示场景

公式与示例（Figma `1555:1598`）：

| 场景 | 公式 | 示例 |
|---|---|---|
| 表单校验 | 出错原因 + 建议动作 | `不能为空，请输入`；`名称重复，请重新输入` |
| 轻提示 | 动作 + 状态 | `创建成功`；`删除失败`；`文件下载中` |
| 异常状态 | 出错原因 + 建议动作 | `网络异常，请刷新`；`暂无数据，请添加`；`未找到结果，请重新输入` |

以上公式句末均无句号。Alert 警告条不是轻提示，但长句同样不加句号。

预览页说明（「预览页不真实计算」「无后端」等）不要写进产品辅助文案、字段 `description` 或成功反馈。
